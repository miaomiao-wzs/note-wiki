# ZFIR020

## 定义
`ZFIR020` 是 SAP 中用于查询实际成本进销存报表的自定义事务码。

## 作用
- 按"公司代码 + 估价范围（工厂）+ 物料"查看指定期间的实际成本进销存情况。
- 显示期初、入库、出库和期末的数量、金额和单价。
- 数据来源于物料分类账，不是简单按物料凭证汇总。
- 适用岗位：成本会计。

## 报表入口

系统中未查询到独立事务码，可通过以下方式进入：

1. SAP 菜单配置的报表入口
2. `SA38` 或 `SE38` → 输入 `ZFIR020` → 执行

## 选择屏幕字段

| 字段 | 必输 | 说明 |
|------|:----:|------|
| 公司代码 | 是 | 核算主体 |
| 会计年度 | 是 | 查询年度 |
| 期间 | 是 | 起始期间；填写起止期间表示累计查询 |
| 工厂/估价范围 | 是 | 按 `BWKEY` 取数 |
| 物料类型 | 否 | 限制原料、半成品、成品等 |
| 物料 | 否 | 具体物料编码 |
| 评估类 | 否 | 财务估价分类 |

## 报表字段说明

### 入库字段
- 入库数量：物料分类账分类 `PC`（价格更改）、`ZU`（收据）、`VP`（其他接收/消耗）的数量合计
- **注意**：入库不是纯采购或生产入库，还包含价格调整

### 出库字段
- 出库数量：物料分类账分类 `VN`（消耗）的数量
- **注意**：出库数量可能显示负数

### 期末字段
- 期末数量 = 期初数量 + 入库数量 + 出库数量
- 期末金额 = 期初金额 + 入库金额 + 出库金额

## 已知限制

1. "入库"包含 `PC`、`ZU`、`VP`，不是纯采购或生产入库
2. "出库"仅按 `VN` 消耗分类汇总
3. 报表不显示货币类型和币种
4. 无法按物料凭证、移动类型、订单、库存地点或批次追溯
5. 若物料没有启用批次管理，库存数据不会存入底表 `MCHB`，标准报表取不到库存数据
