# FI 凭证记账

## 概念定义
FI 凭证记账是 SAP 财务会计中录入、预制、过账、修改、显示、冲销和打印会计凭证的一组基础操作。

## 为什么重要
- 是总账、应收、应付日常工作的基础。
- 会影响总账余额、客户余额、现金流量表项和后续报表查询。
- 凭证字段如凭证日期、过账日期、凭证类型、公司代码、货币、过账码、科目、金额、成本对象等都影响凭证质量。

## 记账方式

### 1. 手工直接过账

最常用的方式，适合日常费用、调整、结转等业务。

| 事务码 | 适用场景 |
|--------|----------|
| `F-02` | 总账凭证录入（最通用） |
| `F-43` | 供应商发票录入 |
| `F-64` | 客户发票预制 |
| `F-90` | 资产购置（有供应商） |

以 `F-02` 为例的操作步骤：
1. 进入 `F-02`，输入凭证日期、过账日期、凭证类型和公司代码。
2. 在行项目中输入科目、金额、过账码。
3. 费用科目（如 `6602*`）需输入成本中心或 WBS，两者不能同时输入。
4. 货币资金科目需维护原因代码，对应现金流量表项。
5. 模拟检查借贷平衡后过账。

#### 参照已有凭证快速录入

如需参照已有凭证快速录入（例如每月重复发生的同类费用），可使用"使用参考过账"：

1. 在 `F-02` 抬头区域点击**"使用参考过账"**按钮。
2. 输入要参照的**凭证编号**、**会计年度**和**公司代码**。
3. 点击回车，系统自动带出行项目信息（科目、金额、成本中心等）。
4. 根据需要修改日期、金额等字段。
5. 模拟检查后过账。

> [!note] 适用场景
> 每月重复发生的同类费用（房租、摊销等）、类似业务批量记账、参照上月凭证做本月调整。参照只是复制行项目内容，新凭证会生成新凭证号。

> [!warning] 成本中心记收入限制
> 收入类科目默认不能记到成本中心，需先通过 `KS02` 开启"记录实际收入"控制。详见 [[wiki/fico/concepts/成本中心收入记账]]。

### 2. 预制凭证方式

适用于需要审核后才正式入账的场景，可分离制单和过账动作。预制凭证不影响总账余额，过账后才正式入账。

1. `F-65` 录入一般预制凭证
2. `FBV2` 修改预制凭证
3. `FBV0` 审批过账

预制凭证过账后凭证号保持不变。

### 3. 批量导入

- `ZFIU001`：凭证批量导入记账功能
- 可导入预制凭证，也可批量导入过账凭证

详见 [[wiki/fico/concepts/凭证批量导入]]。

## 凭证后续处理

| 操作 | 事务码 | 说明 |
|------|--------|------|
| 显示凭证 | `FB03` | 查看过账后的凭证 |
| 修改凭证 | `FB02` | 已过账凭证只能修改少量字段（金额等过账数据不能修改） |
| 冲销凭证 | `FB08` | 总账凭证冲销 |
| 批量冲销 | `F.80` | 总账凭证批量冲销（不建议使用） |
| 重置清账 | `FBRA` | 已清账凭证的冲销 |
| 打印凭证 | `ZFIF001` | 凭证打印 |
| 查找业务单据 | 参见 [[wiki/fico/concepts/凭证追溯业务单据]] | 通过凭证反查采购订单、销售订单等 |

## 常见注意事项

- 费用科目必须输入成本中心或 WBS。
- 货币资金科目必须维护原因代码（现金流量表项）。
- 凭证日期和过账日期决定会计期间。
- 借贷必须平衡。
- 已过账凭证的金额不能修改，只能冲销后重新记账。
