# 固定资产折旧

## 概念定义
固定资产折旧是按资产折旧规则在期间内将资产价值分摊为费用的处理。

## 为什么重要
- 折旧影响期间费用、资产净值和月结结果。
- 折旧异常会同时影响资产子账、总账、资产报表和后续期间折旧计划。

## 工作机制 / 处理流程
1. 维护资产折旧码和使用年限，并确认资产状态、折旧范围和科目确定。
2. 使用 `AFAB` 测试运行折旧，确认运行参数、期间状态和预期结果。
3. 正式后台执行折旧；是否需要重跑、重算或调整，依异常原因、期间状态和目标系统配置核验。
4. 使用 `AFBP` 查看日志，使用 `AW01N` 检查资产价值和折旧期间，使用 `FB03` 查看相关凭证。
5. 发生异常时，先建立“资产—折旧范围—期间—金额—凭证”的证据链，再区分主数据错误、折旧运行错误、计划外折旧和凭证纠正场景。
6. 调整或冲销前核对事务类型、资产类别、折旧范围、科目确定及总账期间；调整后重新检查资产子账、总账和折旧计划。

> [!warning] 调整事务不可套用固定矩阵
> `ABAA` 通常用于计划外折旧，`AB08` 可作为资产凭证冲销入口；`ABMA` 的准确语义以及这些事务的金额方向、影响期间和后续折旧影响依 SAP 版本与配置核验。不能仅凭事务码名称、文章示例或“折旧运行前/后”固定选择事务。

## 异常诊断与调整边界

- 优先使用 `AW01N` 定位异常资产、折旧范围、期间和金额，再用 `AS02` / `AS03` 检查折旧码、使用年限、资产状态及主数据变更。
- 用 `AFBP` 判断折旧运行是否报错、是否生成凭证；用 `FB03` 核对凭证日期、期间、科目、金额和参考信息。
- 当期、历史期间、跨年度、已年结、已报废和已运行折旧的处理边界不同，必须结合期间状态、年度状态、资产状态和会计政策确认。
- `AO78`、`OABU`、负数价值或负数折旧相关选项属于版本/配置依赖，不应未经测试和审批在生产环境放开。
- 不得通过 debug 跳过校验、直接修改 `ANEP` / `ANLC` 等底表或删除资产凭证来修复不一致；应使用正式业务事务并保留测试、审批、回退和审计证据。
