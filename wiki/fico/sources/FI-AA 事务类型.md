## 一句话结论
FI-AA 事务类型是连接资产业务、资产子账和总账过账的规则入口，影响业务性质、借贷方向、资本化标记、价值更新、折旧范围和科目确定；实际 AO 事务码、事务类型映射和字段含义必须以当前系统 IMG 配置为准。

## 关键内容

### 1. 事务类型控制什么
- 区分购置、报废、转移、后资本化、计划外折旧等资产业务。
- 控制资产原值、累计折旧和净值的更新方向，并影响资产历史明细和变动报表。
- 通过事务类型组、科目确定码和折旧范围，将业务规则连接到 AO90 的总账科目配置。
- 事务类型错误时，可能造成资产子账与总账不一致、数量更新异常或处置损益归类错误。

### 2. 配置对象与检查重点
资料提到的常见对象包括：

| 对象 | 资料中的作用 | 使用边界 |
| --- | --- | --- |
| `TABW` | 事务类型核心属性 | 字段含义和版本差异需在系统字典核对 |
| `TABWG` / `V_TABWG` | 事务类型组 | 不要仅凭编号推断业务含义 |
| `TABWI` | 资产类别与事务类型限制 | S/4HANA 新资产会计的适用性需核验 |
| `TABWT` / `TABWD` | 文本、默认事务类型等信息 | 以实际视图和版本为准 |
| `T095A` / `T095B` | AO90 相关科目确定 | 需结合科目表、科目确定码和折旧范围检查 |
| `ANEP` / `ANLC` / `ANLP` | 资产业务数据和期间价值 | 查询前确认数据模型及授权 |

常见配置检查顺序是：事务类型组 → 事务类型属性 → 资产类别限制 → AO90 科目确定 → 测试业务过账 → 资产与总账对账。

### 3. AO73–AO90 映射的核验要求
原文列举了 AO73–AO90、OAXG 等事务码与业务类别的对应关系，但文内对 AO74、AO76、AO77 的描述存在不一致，且不同 SAP 版本、菜单视图和本地配置可能不同。因此本页只记录为“原文提及”，不把映射当作当前系统的确定结论。

建议核验：
1. 从 IMG 的资产会计事务配置进入对应活动，确认事务码和维护视图。
2. 在测试系统检查默认事务类型、事务类型组和借贷/资本化属性。
3. 用已知购置、报废、转移和计划外折旧案例验证资产价值、凭证科目及折旧范围。
4. 通过资产凭证、资产浏览器和总账余额完成子账—总账对账。

### 4. 业务应用
原文以 `100`、`200`、`210`、`300`、`400`、`640/650` 等示例说明购置、报废、出售、转移、后资本化和计划外折旧。它们属于资料中的示例，不应脱离当前系统配置直接作为统一标准。
