# CON2 生产订单按实际作业价格重估

## 来源信息

- 来源类型：用户查询整理 / FICO 综合资料
- 原始位置：用户确认的生产订单月结场景；[[raw/fico/article/202607/FICO.md]]
- 语言：中文
- 适用模块：CO-PC / CO-CCA

## 一句话结论

`CON2` 是“按实际价格重估—集中处理”事务码，用于按照实际作业价格批量重估生产订单，将计划作业价格与实际作业价格之间的差额重新分配到生产订单，主要影响人工、机器和制造费用等作业成本。

> [!warning] 执行顺序和凭证表现需结合系统核验
> 本页整理的是当前资料中的标准理解。作业价格计算、重估是否必跑、过账期间、次级成本要素以及是否生成 FI 凭证，取决于 SAP 版本、成本核算变式和企业配置。正式执行前应先测试运行并检查 CO 凭证及订单成本。

## 一、CON2 的作用

- 批量按实际作业价格重估生产订单。
- 将实际作业价格与原先计入订单的作业价格之间的差额分配到生产订单。
- 调整生产订单中的人工、机器、制造费用等作业成本。
- 为后续生产订单差异计算和订单结算提供更接近实际的成本基础。
- 适用于成本会计的生产成本月结场景。

`CON2` 不是生产订单结算事务码，也不是材料采购价格调整事务码。它首先调整订单中由作业类型计入的作业成本，后续仍需根据月结方案执行差异计算和订单结算。

## 二、重估计算逻辑

基本计算关系为：

```text
实际应承担的作业成本 = 实际作业价格 × 实际报工数量
重估差异 =（实际作业价格 − 原计入作业价格）× 实际报工数量
```

### 示例

某生产订单本月实际报工 500 小时：

- 原计划作业价格：80 元/小时
- 实际作业价格：90 元/小时
- 原已计入订单的作业成本：40,000 元
- 按实际作业价格应承担的作业成本：45,000 元

则：

```text
重估差异 =（90 − 80）× 500
         = 5,000 元
```

执行 `CON2` 后，生产订单的相关作业成本原则上由 40,000 元调整为 45,000 元，增加 5,000 元。若实际作业价格低于原计入价格，则重估结果可能冲减订单成本，借贷方向相应相反。

## 三、CON2 调整的成本范围

`CON2` 主要调整通过作业类型分配到生产订单的成本，例如：

- 人工作业成本；
- 机器作业成本；
- 制造费用作业成本；
- 其他通过成本中心作业类型发送到生产订单的成本。

它通常不直接处理：

- 材料采购价格差异；
- 供应商发票价格差异；
- 生产订单最终结算接收方；
- 产成品库存结算；
- 在产品最终结算。

这些内容分别涉及材料/物料分类账、`CO88` 订单结算或其他业务流程。

## 四、CON2 与生产成本月结的关系

生产订单相关的常见月结逻辑如下，实际先后顺序应按企业方案确认：

```text
成本中心费用归集
    ↓
KSS2 / KSII 计算或分配实际作业价格
    ↓
CON2 按实际作业价格批量重估生产订单
    ↓
KKAO 计算在产品（如适用）
    ↓
KKS1 / KKS2 计算生产订单差异
    ↓
CO88 结算生产订单
    ↓
CKMLCP 对标准价格物料进行差异还原和分摊（如适用）
```

### 关联事务码

| 事务码 | 作用 | 与 `CON2` 的关系 |
|---|---|---|
| `KSS2` | 实际作业价格分割或批量处理，具体含义依系统配置 | 为实际作业价格处理提供前置数据或关联环节 |
| `KSII` | 计算实际作业价格 | 计算作业类型的实际价格，作为重估依据 |
| `KSBT` | 查看作业类型实际价格 | 检查实际作业价格结果 |
| `CON2` | 按实际价格批量重估生产订单 | 将价格差异重新分配到订单 |
| `KKAO` | 计算在产品 | 计算未完工订单的 WIP，和重估后的订单成本有关 |
| `KKS1` / `KKS2` | 计算订单差异 | 通常在重估后重新计算订单差异 |
| `CO88` | 批量结算生产订单 | 结算重估、投入和差异后的订单成本 |
| `KO88` | 单个生产订单结算 | 单个订单结算，不是重估事务码 |

> [!note] 关于 KSS2 和 KSII
> 当前资料对 `KSS2` 的描述包括“实际作业价格批量计算”和“将实际作业价格分割到作业类型”等表述；具体按钮、处理范围和先后关系可能因系统版本及配置不同而不同。正式操作时应以目标系统事务说明、运行日志和企业月结方案为准。

## 五、CON2 与 CO88 的区别

| 对比项 | `CON2` | `CO88` |
|---|---|---|
| 核心动作 | 按实际作业价格重估订单 | 结算生产订单 |
| 处理对象 | 作业价格差异 | 订单归集成本、WIP 和订单差异 |
| 结果 | 生产订单成本被增加或减少 | 成本结转到产成品、在产品或差异接收方 |
| 月结位置 | 通常在订单差异计算和结算之前 | 通常在差异计算之后 |
| 是否等同于 FI 结算 | 不等同 | 涉及 FI 科目时可生成会计凭证 |

可以简单理解为：

> `CON2` 先把生产订单的作业成本调整得更接近实际；`CO88` 再把调整后的订单成本按结算规则转出。

## 六、与当前 CO88 科目资料的关系

此前整理的 `CO88` 科目映射主要包括：

- `1405010000` / `5001020100`：产成品结算；
- `1405020000` / `5001020300`：在产品结算；
- `5001990000` / `1404010000`：生产订单差异结算。

这些科目主要对应订单结算阶段，不能直接作为 `CON2` 的固定科目映射。`CON2` 的重估结果通常先体现在生产订单的 CO 成本行项目中，涉及的次级成本要素、发送方成本中心和接收方生产订单由系统配置决定。

如果 `CON2` 后续影响订单差异，差异可能在 `KKS1/KKS2` 和 `CO88` 阶段继续进入企业配置的差异科目，并在标准价格物料的 `CKMLCP` 中进一步分摊。

## 七、执行后检查

1. 先确认实际作业价格已经正确计算，并检查 `KSBT` 等结果。
2. `CON2` 先使用测试运行，核对订单选择范围、期间、版本和错误信息。
3. 正式执行后查看运行日志，区分成功、警告和错误订单。
4. 使用 `KOB1` 或 `KKBC_ORD` 对比重估前后的生产订单成本。
5. 检查成本中心发送方、生产订单接收方、作业类型和金额是否合理。
6. 重新运行或检查 `KKS1/KKS2`，确认生产订单差异是否发生预期变化。
7. 后续执行 `CO88` 时，检查结算日志、订单余额和 `FB03` 中的 FI 凭证（如有）。
8. 对启用物料分类账的标准价格物料，再使用 `CKM3N`、`CKMVFM` 等检查后续差异分配。

## 八、常见异常方向

如果 `CON2` 重估结果异常，可以优先检查：

- 实际作业价格是否已正确计算；
- 成本中心和作业类型是否维护了有效价格；
- 实际报工数量是否完整、期间是否正确；
- 生产订单是否接收到了正确的作业类型；
- 新增成本中心是否纳入作业分割结构；
- 成本要素是否纳入相应成本要素组或分配结构；
- 作业类型没有报工时，成本是否被系统分摊到其他作业类型；
- 重估后是否重新执行差异计算和订单结算。

任何手工调账或直接修改配置的处理，都应先确认业务原因、权限审批、测试结果和对后续物料分类账的影响。
