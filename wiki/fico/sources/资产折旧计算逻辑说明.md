# 资产折旧计算逻辑说明

## 来源信息
- 来源类型：note / calculator documentation
- 原始位置：`raw/fico/article/202608/asset-depreciation-calculation-logic.md`
- 适用模块：FICO / FI-AA
- 文档日期：2026-08-11
- 计算工具：[通用资产折旧动态测算器](https://miaomiao-wzs.github.io/asset-depreciation-calculator/)

## 一句话结论
本文档解释一个通用资产折旧测算器采用的剩余寿命直线法、累计折旧追平及补提/冲回逻辑；它是测算器的特定计算口径，不代表 SAP FI-AA 所有折旧码、期间控制或目标系统的通用规则。

## 关键内容
- 以资产原值、残值率、导入的往年折旧和计划使用月数计算剩余可折旧金额与正常月折旧。
- 在调整期间将导入的本年折旧与目标累计折旧比较，计算补提或冲回金额。
- 调整完成后以相邻期间目标累计折旧差额计算后续期间折旧，并区分 SAP 所属期间与实际执行月份。
- 页面说明测算器在浏览器本地完成计算；资产数据和计算结果仍应以企业系统记录为准。
