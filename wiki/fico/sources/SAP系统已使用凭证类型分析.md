# SAP 系统已使用凭证类型分析

## 来源信息
- 原始资料：[[raw/fico/article/202608/SAP系统已使用凭证类型分析_20260820.md]]
- 数据范围：系统 RFC 数据连接对应 SAP 客户端的 `BKPF` 历史数据
- 提取日期：2026-08-20

## 核心结论

### 凭证类型不能单独等同于业务来源

识别凭证真实来源时应结合：

```text
BKPF-BLART  凭证类型
BKPF-TCODE  产生凭证的技术事务/入口
BKPF-AWTYP  参考业务对象类型
BKPF-AWKEY  参考业务对象关键字
BKPF-BKTXT  凭证抬头文本
BSEG/ACDOCA 行项目、科目、客户、供应商、成本中心、订单/WBS 等
```

### 系统统计

- 配置凭证类型总数：63 个
- 实际使用过的凭证类型：**34 个**

## 凭证类型分类速查

### 固定资产和历史数据迁移

| 凭证类型 | 名称 | 作用 |
|---------|------|------|
| `AA` | 资产过帐 | 固定资产正式价值业务（购置、报废、转移、转固） |
| `AF` | 折旧过帐 | 固定资产折旧自动过账 |
| `UE` | 数据传输 | 接口或历史数据迁移凭证 |

**AA vs AF vs UE**：
- AA：资产价值正式过账
- AF：资产折旧过账
- UE：数据传输/接口导入

### 客户、供应商、采购发票和销售开票

| 凭证类型 | 名称 | 作用 |
|---------|------|------|
| `DA` | 客户凭证 | 通用客户往来凭证 |
| `DR` | 客户发票 | 非 SD 自动开票的客户发票 |
| `DZ` | 客户付款 | 客户收款及清账 |
| `KA` | 供应商凭证 | 通用供应商往来凭证 |
| `KG` | 供应商贷项凭证 | 供应商贷项和应付冲减 |
| `KP` | 科目维护 | GR/IR 科目维护调整凭证 |
| `KR` | 供应商发票 | 非 MIRO 的供应商发票（费用类、手工类） |
| `KZ` | 供应商付款 | 标准供应商付款和清账 |
| `RE` | 发票－总额 | MM 物流发票校验（MIRO 采购发票） |
| `RV` | 开票凭证转帐 | SD 开票向 FI 传递的应收和收入凭证 |

**KR vs RE**：
- KR：不经过 MIRO 的费用类、手工类或接口类应付发票
- RE：采购订单、收货、GR/IR 相关的 MIRO 发票

**DR vs RV**：
- DR：手工或接口客户发票
- RV：SD 开票流程自动形成的 FI 凭证

### 总账、报销、借支和资金业务

| 凭证类型 | 名称 | 作用 |
|---------|------|------|
| `AB` | 会计凭证 | 通用会计和清账凭证（客户/供应商/总账清账） |
| `BX` | 报销 | 报销工作流产生的费用凭证 |
| `FK` | 付款 | 自定义付款流程凭证 |
| `HK` | 还款 | 员工借款、备用金归还 |
| `JZ` | 借支 | 员工借支、备用金、出差借款 |
| `SA` | 总账科目凭证 | 通用用户手工凭证 |
| `SG` | 总账科目凭证 | 自定义总账凭证（区分 SA） |
| `SK` | 收款凭证 | 自定义收款业务凭证 |
| `SU` | 调整凭证 | 仅总账调整用途 |
| `ZA` | 评估 | 外币评估、期末估值调整 |
| `ZJ` | 资金调度 | 资金调拨、归集、划转 |
| `Z2` | 调整凭证（制费） | 制造费用调整凭证 |

**AB vs SA vs SG**：
- AB：清账凭证（FB1D/FB1K/FB1S）
- SA：通用手工调账（FB50/F-02/FB01）
- SG：受控接口或特定业务总账凭证

**报销闭环**：
- JZ（借支）→ BX（报销）→ HK（还款）→ FK（付款）→ SK（收款）

### 成本控制、研发分摊和项目结算

| 凭证类型 | 名称 | 作用 |
|---------|------|------|
| `CO` | CO 过账 | 生产确认、订单结算、重过账、分配 |
| `Y1` | 研发分摊凭证 | 研发费用分摊和结转 |
| `Z1` | 项目结算 | WBS/项目/订单向接收方结算 |

### 物料、库存、价格和物料分类账

| 凭证类型 | 名称 | 作用 |
|---------|------|------|
| `ML` | ML 结算 | 物料分类账期末结算 |
| `PR` | 价格更改 | 物料价格调整、标准价格发布 |
| `WA` | 发货 | 一般库存发出（领料、报废） |
| `WE` | 收货 | 一般库存收货 |
| `WI` | 库存凭证 | 盘点差异调整 |
| `WL` | 发货/交货 | 销售交货相关库存发出 |

**WA vs WE vs WI vs WL**：
- WE：收货（库存增加）
- WA：一般货物发出（领料、报废）
- WL：销售交货发出
- WI：盘点差异调整

## 凭证类型管理建议

建议建立管理台账，梳理以下边界：

```text
AB / SA / SG            清账、通用手工凭证、受控总账凭证的边界
FK / KZ                 自定义付款与标准供应商付款的边界
AA / UE                 资产过账与数据迁移凭证的边界
BX / JZ / HK / FK / SK  报销、借支、还款、付款和收款工作流的闭环
KR / RE                 非 PO 供应商发票与 MIRO 采购发票的边界
WA / WL                 一般货物发出与销售交货发出的边界
CO / Y1 / Z1 / Z2       标准 CO、研发分摊、项目结算和制造费用调整的边界
```
