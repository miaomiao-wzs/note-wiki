## 核心主题

### 报表勾稽与财务报表

- 资产负债表基本关系：资产 = 负债 + 所有者权益。
- 未分配利润与本期净利润存在勾稽关系，需要关注利润分配、盈余公积和股利分配的影响。
- 现金流量表期末现金及现金等价物余额应与资产负债表货币资金期末余额核对。
- `IDCNBSAIS` 查询资产负债表时应注意期间口径，利润表和资产负债表期间必须一致。
- 相关页面：[[wiki/fico/concepts/财务报表勾稽检查]]、[[wiki/fico/entities/IDCNBSAIS]]。

### 常用事务码总览

资料集中列出大量 FICO / CO / MM / SD / PS 事务码，可作为快速索引使用。代表性事务码包括：

- 总账与凭证：`F-02`、`FB50`、`FV50`、`FB03`、`FB08`、`FBV2`、`FBV0`、`FAGLL03H`、`FAGLB03`。
- 采购发票与 GR/IR：`MIRO`、`MIR6`、`MIR7`、`MR8M`、`MR11`、`MR11SHOW`、`F.13`、`F.19`。
- 客户/供应商往来：`FBL1N`、`FBL1H`、`FK10N`、`FBL5N`、`FD10N`、`F-44`、`F-47`、`F-54`、`F-32`、`IDCNAP`、`IDCNAR`。
- 固定资产：`AFAB`、`AFBP`、`AFAR`、`ABAVN`、`ABUMN`、`ABAON`、`ABZON`、`ABNAN`、`AS91`、`AIAB`、`AIBU`、`OAAQ`。
- 成本中心与生产成本：`KS01`、`KS02`、`KS03`、`KSU5`、`KSV5`、`KSS2`、`KSII`、`CON2`、`CO88`、`CO43`、`KKAO`、`KKS1`。
- 物料价格与物料分类账：`MR21`、`MR22`、`CK11N`、`CK40N`、`CK24`、`CKMLCP`、`CKM3N`、`CKMVFM`、`CKMS`、`CKMM`。
- WBS / PS：`CJ20N`、`CJ02`、`CJ88`、`CJ8G`、`CJI3`、`CJI3N`、`CN41N`、`CN43N`、`CNMASS`、`CNMASSCREATE`。
- 自开发报表和接口：`ZFIR009`、`ZFIR020`、`ZFIR037`、`ZFIR040`、`ZFIR043`、`ZFIR047`、`ZFIR053`、`ZFIU010`、`ZFIU027`、`ZFIU041`、`ZFIU042`、`ZFIU052`。

### 凭证冲销场景

资料按业务来源区分冲销工具：

- 总账凭证：`FB08`，批量冲销可用 `F.80`。
- 清账凭证：`FBRA`。
- 销售发票开票凭证：`VF11`。
- 采购发票校验凭证：`MR8M`。
- 资产凭证：`AB08`。
- 物料分类账关账：`CKMLCP` 的冲销功能。
- 项目结算：`CJ8G`。
- 生产工单结算：`CO88`。
- 生产工单价格重估：`CON2`。
- 费用分摊/分配：`KSV5`、`KSU5`。

相关页面：[[wiki/fico/concepts/凭证冲销]]、[[wiki/fico/entities/MR8M]]、[[wiki/fico/entities/CKMLCP]]。

### 供应商、客户与往来清账

- 供应商余额可查 `FK10N`，供应商行项目可查 `FBL1N` / `FBL1H`。
- 客户余额可查 `FD10N`，客户行项目可查 `FBL5N`。
- `ZFIR009` 可用于客户供应商往来查询或客商余额三栏式。
- `ZFIR053` 可用于外部单位往来明细，`ZFIR047` 可用于客户/供应商账龄报表。
- 供应商清账场景涉及 `F-44`、`F-04`、`FBRA`、未清项、部分清账和剩余清账的差异。
- `IDCNAP` / `IDCNAR` 用于供应商/客户账龄分析，关键日期、基准日期和付款条件会影响账龄天数。

相关页面：[[wiki/fico/entities/FBL1N]]、[[wiki/fico/entities/FBL1H]]、[[wiki/fico/entities/FK10N]]、[[wiki/fico/entities/F-44]]、[[wiki/fico/entities/IDCNAP]]、[[wiki/fico/entities/IDCNAR]]、[[wiki/fico/concepts/供应商付款]]、[[wiki/fico/concepts/客户收款]]。

### 采购发票、暂估与 GR/IR

- 采购发票校验涉及 `MIRO`、`MIR6`、`MIR7`、`MR8M`。
- 采购收货未到票时，典型分录为借记原材料/存货，贷记 GR/IR 暂估科目。
- 发票校验时冲销 GR/IR，并确认进项税和应付账款。
- `MR11` 用于处理未清 GR/IR 项目，`F.13` 用于自动清账，`F.19` 用于 GR/IR 重分类。
- 原文也记录了“基于收货的发票验证”和“发票收据标识”的区别：前者决定发票如何与收货匹配，后者决定行项目是否需要发票。

相关页面：[[wiki/fico/concepts/发票校验]]、[[wiki/fico/concepts/GRIR 自动清账]]、[[wiki/fico/entities/MR11]]、[[wiki/fico/entities/F.13]]、[[wiki/fico/entities/F.19]]。

### 成本中心、成本对象与成本月结

- 成本中心是管理会计中的责任单元，用于费用计划、归集、分析、分摊和考核。
- 成本对象包括成本中心、内部订单、销售订单、生产订单、维修工单、WBS、成本收集器等。
- 成本月结涉及辅助部门费用分摊、实际作业价格计算、生产订单重估、在制品计算、差异计算、订单结算和物料分类账。
- 常见事务码包括 `KSU5`、`KSV5`、`KSS2`、`KSII`、`CON2`、`CO43`、`KKAO`、`KKS1`、`CO88`、`CKMLCP`。
- 原文记录了 KSII 作业数量为零但仍有成本、成本月结后销售成本异常、费用分摊负数、停产月份成本处理等问题排查思路。

相关页面：[[wiki/fico/concepts/成本中心]]、[[wiki/fico/concepts/物料分类账差异处理]]、[[wiki/fico/concepts/生产工单跨月TECO与物料差异结算]]、[[wiki/fico/concepts/生产工单收货与质检取样成本]]。

### 物料价格与物料分类账

- 资料区分标准价 `S` 与移动平均价 `V` 的适用场景、优缺点和转换限制。
- `MR21` 调整物料价格，`MR22` 调整库存总价值。
- 物料分类账月结涉及单级差异、多级差异、库存覆盖检查、实际成本还原、未分配差异和尾差处理。
- 未分摊差异可能来自库存不足、工单有投入无产出、工单结算数量大于库存、跨月发票校验、物料价格控制切换、返工工单等。
- 原文还引用了物料分类账月结后的后续处理、重置物料分类账和启用物料分类账后系统凭证变化等材料。

相关页面：[[wiki/fico/concepts/物料价格控制]]、[[wiki/fico/concepts/物料分类账差异处理]]、[[wiki/fico/entities/CKMLCP]]。

### 固定资产与 EAS 接口

- 固定资产相关内容包括折旧、报废、跨公司转移、资产追加价值、在建工程转固、历史资产、资产批导和资产盘点。
- 常用事务码包括 `AFAB`、`AFBP`、`AFAR`、`ABAVN`、`ABUMN`、`ABAON`、`ABZON`、`AS91`、`AIAB`、`AIBU`、`OAAQ`、`ZFIU002`、`ZFIU042`。
- 资料记录了 SAP 固定资产推送 EAS 的接口逻辑、资产主数据字段取值优先级、EAS 公司/资产类别/业务类型/科目/成本中心匹配表等。
- 固定资产采购订单收货后是否直接入账，与科目分配类别、发票校验和 `OME9` 配置相关。

相关页面：[[wiki/fico/concepts/固定资产主数据]]、[[wiki/fico/concepts/在建工程转固反向处理]]。

### WBS、项目结算与研发费用

- WBS 可通过 `CJ20N` 创建，通过 `CJ02` 维护，通过 `CJ88` / `CJ8G` 结算。
- WBS 批量创建和维护涉及 `CNMASSCREATE`、`CNMASS`、`CNMASSSTATUS`、`ZPSU002`。
- 研发费用场景中，`5301*` 科目可通过项目结算转入 `6602*` 科目，涉及 WBS 结算规则。
- 统计型 WBS 可用于费用归集，但需要控制与成本中心同时出现时的真实成本对象归属。

相关页面：[[wiki/fico/concepts/WBS 元素]]、[[wiki/fico/entities/CJ20N]]。

### 销售开票、金税发票与未开票处理

- 销售开票和冲销涉及 `VF01`、`VF02`、`VFX3`、`VF11`。
- 形式发票与金税发票税额存在税差时，可通过 `VF02` 定价条件中的税额/应收调整字段处理。
- `ZFIR043`、`ZFIU026` 等用于金税发票相关维护或清单查询。
- 月结场景中，未开票收入和成本可能通过手工记账方式确认，合同资产、库存商品差异和一次性客商需要特别注意。

相关页面：[[wiki/fico/concepts/销售开票]]、[[wiki/fico/entities/ZFIR043]]。
