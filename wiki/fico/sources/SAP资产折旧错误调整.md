# SAP 资产折旧错误调整

## 来源信息

- 来源类型：web / Markdown 剪藏
- 原始位置：`raw/fico/article/202607/SAP资产折旧调错了怎么办？用ABMA冲销与ABAA补提（附AO78配置）.md`
- 原文来源：[CSDN 文章](https://blog.csdn.net/woniu_maggie/article/details/159688893)
- 适用模块：FICO / FI-AA
- 整理日期：2026-07-28
- 可信度说明：原文包含可复用的排查线索，也包含重复段落、未经证实的配置描述、固定化的正负号结论、危险伪代码和疑似 AI 扩写；本页不能直接替代目标系统配置说明、SAP 版本文档或生产变更审批。

## 一句话结论

处理资产折旧异常时，应先用资产价值浏览器、资产主数据、折旧运行日志和会计凭证建立“资产—折旧范围—期间—金额—凭证”的证据链，再根据目标系统的资产会计配置、期间状态和年度状态选择调整或冲销方案。`ABAA`、`ABMA`、`AB08` 的具体行为、金额方向和是否影响后续折旧，不能仅依据文章标题或事务码名称推断。

## 可复用的异常诊断链

### 1. 先定位异常对象

记录至少以下信息：

- 公司代码、资产编号及子编号；
- 异常折旧范围、会计年度和期间；
- 计划折旧、实际折旧、计划外折旧或手工调整的区分；
- 异常金额、资产净值及相关资产凭证号；
- 是否已经运行 `AFAB`、是否已经生成总账凭证、相关期间是否已关闭。

不要先根据金额正负或文章中的示例事务类型决定借贷方向。方向必须回到资产价值字段、事务类型属性、折旧范围和凭证核对。

### 2. 使用资产与凭证工具交叉检查

| 检查对象 | 入口 | 目的 |
| --- | --- | --- |
| 资产价值、折旧范围、期间变化 | `AW01N` | 定位异常期间、折旧金额、累计折旧和资产净值变化 |
| 折旧码、使用年限、资产状态及主数据变更 | `AS02` / `AS03` | 判断异常是否由主数据或资产状态引起 |
| 折旧运行结果和错误信息 | `AFBP` | 区分折旧运行错误、未生成凭证和过账失败 |
| 资产相关会计凭证 | `FB03` | 核对凭证日期、过账期间、科目、金额和参考信息 |
| 折旧计划与运行状态 | `AFAB` | 确认测试运行/正式运行状态及是否需要按现行方案重新运行 |

建议同时保留资产子账、总账凭证和运行日志的查询结果，避免只凭一张截图判断调整是否成功。

## 事务职责与边界

| 事务码 | 原文定位 | 本页可确认的边界 | 不应直接推断的内容 |
| --- | --- | --- | --- |
| `AFAB` | 执行折旧运行 | 用于折旧运行及测试/正式执行场景；具体运行状态和重跑条件依系统设置 | 不应据此推导所有异常都必须重跑，或固定先后顺序 |
| `AFBP` | 查看折旧运行结果 | 用于查看运行日志、错误和结果 | 不等于资产凭证冲销或调整工具 |
| `ABAA` | 计划外折旧 | 通常作为计划外折旧业务入口 | 正负数、借贷方向、影响期间、是否改变未来计划依配置和业务场景核验 |
| `ABMA` | 原文称用于折旧冲销 | 只能作为目标系统待核验的候选入口；应先确认事务定义、允许的业务状态和生成凭证逻辑 | 不能写成通用的“历史折旧冲销”工具，也不能据此固定借贷方向 |
| `AB08` | 资产凭证冲销 | 可作为资产凭证冲销入口，前提是原凭证状态、期间和业务类型允许 | 不是删除资产记录的工具，也不是任何状态下都适用 |
| `AW01N` | 资产价值浏览器 | 用于查看资产价值、折旧范围和期间变化 | 不替代凭证和配置核验 |

> [!warning] 事务行为必须在目标系统核验
> 在测试系统用最小可复现资产验证事务类型、凭证生成、资产价值更新、折旧计划变化和总账影响，再决定生产处理。未确认前，不要把 `ABMA`、`ABAA` 或 `AB08` 组合成固定处理矩阵。

## AO78、事务类型与负数价值：配置依赖

原文提到通过 `AO78` 创建或复制反向事务类型，并结合 `OABU`、`AS02` 等选项允许负数折旧范围或负数资产价值。此类内容受 SAP 版本、资产会计模型、折旧范围设置、资产类别和事务类型属性影响，不能从示例编号直接推广。

核验时至少检查：

1. `AO78` 当前系统的维护对象、事务类型组、借贷方向、资本化/非资本化属性及价值更新属性；
2. 事务类型是否允许用于目标资产类别、折旧范围和业务场景；
3. `OABU` 是否存在相关负数过账控制，以及该设置的适用范围和审批要求；
4. `AS02` 是否允许目标资产主数据出现负数价值或负数相关字段，以及这是否符合企业会计政策；
5. `AO90` 科目确定、折旧范围过账设置和凭证类型是否会产生预期科目；
6. 测试过账后，资产子账、总账、折旧计划和资产报表是否一致。

原文中的 `Z01`、`Z02`、`640`、`650` 等编号只可视为文章示例。事务类型编号、正负号和借贷方向不得脱离当前系统配置写成标准规则。

> [!danger] 负数价值不是通用修复手段
> 允许负数价值或负数折旧可能影响资产净值、折旧基准、报表和后续处置。任何此类设置都必须有业务依据、目标系统核验、测试证据、审批、备份和可回退方案；不能为绕过校验而在生产系统临时放开。

## 跨期间与跨年度边界

处理前应将场景至少分为以下维度，而不是套用“折旧运行前/后”的单一矩阵：

- 当期与历史期间；
- 当前年度与已结转年度；
- 折旧运行前与已生成折旧凭证后；
- 期间开放与期间已关闭；
- 资产在用、已报废、已转移或已进行其他处置；
- 资产原值错误、累计折旧错误、计划外折旧错误和凭证错误。

跨期、跨年度、已年结或已报废资产的处理方式，可能涉及资产年度关闭、总账期间、折旧范围状态、税务和报表影响。必须由 FI-AA 顾问结合目标系统版本和企业会计政策确认。不能因为某个事务在测试系统可执行，就认为生产系统可以直接跨期冲销或重新打开期间。

## 原文内容分层

### 可作为排查线索

- 用 `AW01N` 观察资产价值、折旧范围和期间变化；
- 用 `AS02` / `AS03` 检查折旧码、使用年限、资产状态和相关主数据；
- 用 `AFBP` 查看折旧运行日志，用 `FB03` 核对会计凭证；
- 在测试系统使用小范围测试资产验证调整结果，并完成资产子账与总账对账；
- 将 `ABAA` 作为计划外折旧入口、`AFAB` 作为折旧运行、`AB08` 作为资产凭证冲销入口进行初步定位。

### 必须标记为待系统核验

- `ABMA` 是否能处理特定历史折旧冲销，以及其准确业务语义；
- `ABAA`、`ABMA` 的金额方向、借贷方向和影响期间；
- `AO78` 事务类型复制关系，以及 `Z01/Z02/640/650` 等示例编号；
- `OABU`、`AS02` 负数价值/负数过账选项的可用性和适用范围；
- 跨期间、跨年度、已年结、已运行折旧和已报废资产的处理路径；
- 调整后是否必须重新运行 `AFAB`，以及重跑对折旧计划和凭证的影响。

### 不纳入知识库结论

以下内容不作为操作建议或标准结论：

- 将 `AB08` 描述为删除资产记录，或声称任何状态都可以使用；
- 文章中的直接删除 `ANEP` 记录、直接更新 `ANLC` 等底表伪代码；
- “折旧运行前固定用 `AB08`、运行后固定用 `ABMA`”的无条件处理矩阵；
- 固定的正负号、借贷方向和事务类型编号规则；
- `ABST2`、`ABZON`、重建索引等缺乏上下文和可靠依据的扩展结论；
- 未经审计证据支持的改善比例、案例数据或会议记录建议。

> [!danger] 禁止直接修改 FI-AA 底表
> 不得通过文章示例中的直接删除 `ANEP` 记录、直接更新 `ANLC` 或类似方式修复资产凭证、期间价值或资产主数据。也不得通过 debug 跳过校验、直接改表或删除日志掩盖不一致。此类行为可能破坏资产子账、总账和审计链，必须走正式纠正、测试、审批和回退流程。

## 测试、验证与对账清单

在任何生产调整前，至少完成：

- [ ] 确认异常资产、折旧范围、期间、年度、原凭证和异常金额；
- [ ] 保存 `AW01N`、`AFBP`、`FB03` 和资产主数据检查结果；
- [ ] 在测试系统复制同类资产状态和配置，验证候选事务行为；
- [ ] 核对事务类型、资产类别、折旧范围、科目确定和期间状态；
- [ ] 检查调整前后资产原值、累计折旧、净值、折旧计划和报表变化；
- [ ] 核对资产子账与总账科目、金额、凭证日期和过账期间；
- [ ] 明确审批人、执行权限、备份/回退方案和审计记录；
- [ ] 对跨期、跨年度、已年结或已报废场景单独取得 FI-AA 和财务负责人确认。
