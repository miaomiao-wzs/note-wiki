# FICO 特殊业务与期初边界

## 来源信息

- 来源类型：article / Markdown 综合笔记
- 原始位置：`raw/fico/article/202607/FICO.md`
- 适用模块：FICO，涉及 MM、税务、采购、PS、AR、AA 和 CO
- 整理范围：提炼特殊业务、期初导入和跨模块边界；现场经验、高风险动作及版本/配置依赖均保留核验标记。

## 一句话结论

农产品税务、免费赠送、运费、统计型 WBS、承兑、期初导入和物料分类账重置都不是只靠一个事务码即可确定的标准流程。应先确认税务政策、评估和科目配置、成本对象、接口设计、期间状态及审批边界，再在测试系统验证。

## 农产品税务与免费赠送

### 税务处理线索

原文记录了两类需要区分的业务：

- 真正免税且不抵扣时，采购订单可能使用 0% 税率，发票校验不形成进项税分录。
- 免税但允许计算抵扣时，原文记录过 9% 税率、定价计算和手工调整税额/净价的做法。

上述内容只表示原始资料中的业务线索，不能直接作为税务结论。实际税率、可抵扣性、价税分离公式、税码和进项税科目必须由税务政策、本地化方案及目标系统配置共同确认。手工调整税额前，应明确审批、凭证影响和申报口径。

### 免费赠送

原文记录的场景包括：

- 无采购订单的免费入库可能使用 `501`，科目由 `OBYC` 和评估配置决定。
- 全部免费采购订单可能以 `101` 收货，只产生物料凭证。
- 部分免费行可能通过免费标识或零金额处理，使数量和单位价格发生变化。

移动类型、评估类、税务处理、库存价值和后续发票关系依企业配置而异。不得只依据以上移动类型直接在生产系统过账；应先用测试单据核对物料凭证、会计凭证和税务结果。

## 发票页签与运费边界

### 发票校验控制

- “基于收货的发票验证”通常影响发票与收货数量的匹配方式；勾选后，未收货发票可能被限制或报错。
- “发票收据标识”影响采购项目是否要求发票；免费项目可能存在不同的默认行为。
- 强制三单匹配、警告/错误消息和免费项目的实际行为取决于采购订单、供应商、物料和消息配置。

相关内容参见 [[wiki/fico/concepts/发票校验]]；具体配置必须在测试系统验证，不应把原始资料的现场描述当作跨版本标准结论。

### 运费成本化与费用化

- **成本化线索**：采购订单维护运费条件，按行项目或抬头分摊；运费进入物料成本，相关自动过账可能涉及 `BSX`、`WRX`、`FR1`。
- **费用化线索**：计划外运费在 `MIRO` 中直接进入物料成本或费用科目；也可能通过 `FB50`/`F-02` 记入成本中心、WBS 或内部订单。
- 已知运费供应商、收货时确定供应商、服务采购订单和 TMS 结算会改变处理方式。

成本口径、条件类型、供应商发票流程和成本对象必须由企业方案确认。不得仅凭 `BSX`、`WRX` 或 `FR1` 的名称推断目标系统科目。

相关页面：[[wiki/fico/concepts/运费成本化]]、[[wiki/fico/concepts/运费费用化]]、[[wiki/fico/sources/采购运费处理方式]]。

## 统计型 WBS 与实际成本对象

统计型 WBS 可以作为统计归集或附加分析维度，但不应未经确认就视为实际成本对象。原文提示：

- 统计型 WBS 与成本中心同时出现在过账或接口中时，应明确真实成本接收方。
- 领料、手工凭证和接口过账需要检查 WBS 是否允许作为成本对象；必要时通过字段状态、BAPI 或自开发校验控制。
- 研发费用通过项目结算转入损益科目的做法依结算规则、接收方和科目配置而定。

相关页面：[[wiki/fico/concepts/WBS 元素]]、[[wiki/fico/concepts/项目成本对象]]。跨公司代码结算、研发科目映射和统计型 WBS 的可记账行为均标记为“待目标系统核验”。

## 承兑与现金流

原文记录：收到承兑和承兑到期收款可能使用同一原因代码；收到承兑进入销售管理系统，到期收款不再重复进入；现金流量表只体现到期收到货款的现金流。

这属于企业接口和现金流原因代码配置的现场经验。应核对应收票据/应收账款科目、原因代码、销售管理接口、现金流量表映射和实际凭证，不得把该描述当成所有系统的标准现金流规则。

## 期初库存边界

- 期初库存导入前需确认价格控制、物料分类账启用状态、特殊库存、未结收货/发票和期初数量金额。
- 原文记录 V 价可按金额导入，S 价方案可能涉及临时切换价格控制或使用 `561`/`562` 等移动类型；这些方案会影响库存价值、差异和后续物料分类账。
- 有库存、特殊库存或未结业务时，S/V 转换通常不能直接执行。任何清库存、改价、期初导入和再建库存的方案必须先测试并保留差异解释。

相关页面：[[wiki/fico/concepts/物料价格控制]]、[[wiki/fico/concepts/物料分类账差异处理]]。具体步骤、期间和移动类型需以目标系统和期初方案审批为准。

## 期初资产导入与重置边界

- `ZFIU002` 被原文记录为固定资产批量导入入口；表格列数、起始行、日期格式和金额格式属于自开发程序约束，必须查当前程序校验。
- 期初资产错误处理原文涉及删除凭证、重置资产或调试跳过校验等方式。这些内容只能作为历史现场记录，不能整理成 SOP。
- `FINS_DELETE_DOCUMENTS`、`OBR1`、`OABL`、直接改底表或 debug 跳过校验都属于极高风险/可能不可逆动作，必须满足正式审批、完整备份、测试演练、回退方案和审计要求；生产系统不得未经授权复现。
- 上线后如需纠正期初数据，应优先评估标准冲销、调整凭证或受控迁移方案，并由 FI-AA、技术和审计角色共同确认。

相关页面：[[wiki/fico/concepts/固定资产主数据]]、[[wiki/fico/concepts/在建工程转固反向处理]]。

## CKMLCP、KSII 与月结边界

- CKMLCP 结算后应检查期间状态、物料价格和未分配差异；`CKM3N`、`CKMVFM`、`CKMS` 可作为分析入口，具体报告和状态码需目标系统核验。
- “CKMLCP 完成后当月不得再发生物料移动”是原始资料中的月结控制经验，应作为企业关账规则验证，不直接当作所有系统的技术限制。
- `KSII` 实际作业价格通常与实际成本和实际作业数量有关。作业量为零但存在成本时，应先排查漏报工、成本中心借方和分割配置；“继续记账/强制过账”只能作为经审批的例外处理，不能掩盖业务数据缺失。
- 物料分类账重置、删除成本核算数据或重新激活属于高风险/不可逆操作，不写成无条件推荐步骤。

相关页面：[[wiki/fico/concepts/物料分类账差异处理]]、[[wiki/fico/concepts/财务月结]]。

## 核验清单

1. 核对税码、税率、抵扣政策、采购条件和自动过账配置。
2. 用测试订单/发票/库存移动验证免费赠送和运费的数量、金额、税额与科目。
3. 明确统计型 WBS、成本中心和实际成本对象的优先级及接口校验。
4. 对承兑业务核对原因代码、现金流映射、接口消息和实际凭证。
5. 在期初导入前确认物料价格、物料分类账、资产会计年度、期间状态和未结业务。
6. 对任何重置、删除、改底表或 debug 方案执行授权、备份、测试、回退和审计检查。

> [!danger] 高风险操作不是标准 SOP
> `FINS_DELETE_DOCUMENTS`、`OBR1`、`OABL`、物料分类账重置、直接改底表、debug 跳过校验、跨期冲销或临时打开生产账期均不得在没有正式授权和回退方案的情况下执行。
