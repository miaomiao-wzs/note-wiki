# CO88 生产订单结算与会计分录

## 来源信息

- 来源类型：用户补充 / FICO 综合资料
- 原始位置：用户确认的生产订单结算科目映射；[[raw/fico/article/202607/FICO.md]]
- 语言：中文
- 适用模块：CO-PC / FI / MM

## 一句话结论

`CO88` 用于批量结算生产订单，将生产订单归集的实际成本、在产品和生产差异按照结算规则结转到库存、在产品或差异接收科目，并在涉及 FI 科目时生成会计凭证。具体借贷方向和金额以企业配置及实际结算凭证为准。

> [!warning] 科目和分录需以实际凭证为准
> 本页的科目映射来自当前企业提供的科目名称，分录是典型业务方向，不代表所有 `CO88` 场景都固定生成同一组分录。执行前应在测试运行、结算日志和 `FB03` 凭证中核对实际结果。

## 一、CO88 的作用

- 批量结算生产订单。
- 将生产订单上归集的材料、人工、制造费用和其他实际成本按结算规则转出。
- 对完工订单结算产成品价值和生产差异。
- 对未完工订单结算在产品（WIP）。
- 将 CO 中的订单结算结果传递到 FI，必要时生成 FI 会计凭证。
- 使生产订单在月结后达到应有的余额状态；若仍有余额，需要结合订单状态、结算规则、WIP、差异和凭证进行排查。

## 二、CO88 在成本月结中的位置

生产订单相关的常见月结逻辑如下，实际顺序依系统版本、企业配置和月结方案确定：

1. 完成生产订单收货、报工和相关费用归集。
2. `CON2`：按实际作业价格对生产订单进行重估（如适用）。
3. `CO43`：计算或分摊辅助生产部门的间接费用（如适用）。
4. `KKAO`：计算在产品（WIP）。
5. `KKS1` / `KKS2`：计算生产订单差异。
6. `CO88`：批量结算生产订单。
7. `CKMLCP`：对启用物料分类账的标准价格物料继续进行差异还原和分摊。
8. 使用 `FB03`、`KOB1`、`KKBC_ORD`、`CKM3N` / `CKMVFM` 等检查凭证和差异去向。

## 三、当前系统的科目映射

### 1. 产成品结算

| 科目 | 名称 | 业务含义 |
|---|---|---|
| `1405010000` | 库存商品 | 产成品库存接收科目 |
| `5001020100` | 生产成本-转出-产成品 | 生产成本转出至产成品的对方科目 |

典型业务方向：

```text
借：1405010000  库存商品
    贷：5001020100  生产成本-转出-产成品
```

该方向表示将产成品价值结算进入库存商品。需要注意，产成品入库的原始价值可能已经在生产收货时产生；`CO88` 是否再次形成完整的库存结算分录，取决于生产订单结算规则及系统设计。

### 2. 在产品结算

| 科目 | 名称 | 业务含义 |
|---|---|---|
| `1405020000` | 在产品 | 在产品资产接收科目 |
| `5001020300` | 生产成本-转出-在产品 | 在产品成本转出科目 |

典型业务方向：

```text
借：1405020000  在产品
    贷：5001020300  生产成本-转出-在产品
```

该方向表示将尚未完工生产订单归集的部分成本暂时结转到资产负债表的在产品科目。

下期或订单完工时，可能发生在产品冲回，方向通常相反：

```text
借：5001020300  生产成本-转出-在产品
    贷：1405020000  在产品
```

### 3. 生产订单差异结算

| 科目 | 名称 | 业务含义 |
|---|---|---|
| `5001990000` | 生产成本-差异转出 | 生产订单差异转出或损益承接科目 |
| `1404010000` | 材料成本差异-生产指令单 | 生产指令单材料成本差异承接科目 |

在实际成本高于标准成本、形成不利差异的典型情况下，可表现为：

```text
借：5001990000  生产成本-差异转出
    贷：1404010000  材料成本差异-生产指令单
```

如果实际成本低于标准成本，或者系统将差异定义为有利差异，借贷方向可能相反：

```text
借：1404010000  材料成本差异-生产指令单
    贷：5001990000  生产成本-差异转出
```

`1404010000` 的后续去向还可能受到物料价格控制和物料分类账影响。对标准价格物料，差异通常还需要在 `CKMLCP` 中继续分摊到期末库存、销售成本或下阶物料。

## 四、分录示例

### 示例一：产成品结算

假设产成品按标准成本 100,000 元结算：

```text
借：1405010000  库存商品                         100,000
    贷：5001020100  生产成本-转出-产成品           100,000
```

### 示例二：月末在产品结算

假设未完工生产订单计算出在产品金额 30,000 元：

```text
借：1405020000  在产品                          30,000
    贷：5001020300  生产成本-转出-在产品          30,000
```

### 示例三：生产订单不利差异结算

假设生产订单实际成本 120,000 元，产成品标准成本 100,000 元，形成 20,000 元生产差异：

```text
借：5001990000  生产成本-差异转出                 20,000
    贷：1404010000  材料成本差异-生产指令单         20,000
```

以上示例用于说明科目关系。实际凭证可能按差异类别、物料、订单和结算接收方拆分为多行，也可能出现不同的借贷方向。

## 五、CO88 与其他事务码的关系

| 事务码 | 作用 | 与 CO88 的关系 |
|---|---|---|
| `CON2` | 批量生产订单价格重估 | 将实际作业价格差异重新分配到生产订单 |
| `CO43` | 计算生产订单相关间接费用 | 将间接费用归集或分配到订单，视配置而定 |
| `KKAO` | 计算在产品 | 为未完工订单计算 WIP 金额 |
| `KKS1` / `KKS2` | 计算订单差异 | 先计算差异，`CO88` 再按结算规则结算 |
| `KO88` | 单个生产订单实际结算 | `CO88` 的单个订单处理方式 |
| `CKMLCP` | 物料分类账实际成本核算 | 对标准价格物料的差异进行后续还原和分摊 |
| `FB03` | 显示 FI 会计凭证 | 检查 `CO88` 产生的会计凭证 |
| `KOB1` | 查看订单实际成本 | 检查生产订单结算前后的 CO 行项目 |

## 六、执行后如何核对

1. `CO88` 先执行测试运行，检查选择范围、订单状态、结算规则和错误信息。
2. 正式执行后保存结算日志，记录处理成功、警告和错误订单。
3. 查看订单余额，确认完工订单是否已经结算到预期状态。
4. 如生成 FI 凭证，用 `FB03` 检查：
   - 借贷方向；
   - 金额；
   - 生产订单号；
   - 物料号；
   - 差异类别；
   - 成本对象和功能范围；
   - 相关 CO 凭证号。
5. 用 `KOB1` 或 `KKBC_ORD` 查看订单实际成本和结算行项目。
6. 对启用物料分类账的物料，用 `CKM3N`、`CKMVFM` 或相关物料分类账报表检查 `1404010000` 差异的后续分配。
7. 若订单余额不为零，重点排查：订单是否未完整结算、结算规则是否正确、WIP 是否计算、结算凭证是否生成、是否存在手工投料或跨期间业务。

## 七、关键判断

- `KKS1` / `KKS2` 是计算差异，`CO88` 是执行订单结算，二者不是同一个动作。
- 完工订单重点关注产成品结算和生产差异；未完工订单重点关注在产品结算。
- `CO88` 产生的 FI 分录不应只凭科目名称推断，最终必须以结算日志和 `FB03` 实际凭证为准。
- 对标准价格物料，生产订单结算形成的差异可能只是物料分类账差异链条中的一个环节，后续还需通过 `CKMLCP` 进行实际成本还原。
- 任何手工调整生产投入、转出或差异科目的操作，都应先确认业务原因、系统配置、审批要求和是否会影响后续物料分类账。
