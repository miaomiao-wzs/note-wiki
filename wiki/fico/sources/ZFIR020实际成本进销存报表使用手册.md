# ZFIR020 实际成本进销存报表使用手册

## 来源信息
- 原始资料：[[raw/fico/article/202608/ZFIR020实际成本进销存报表使用手册.md]]
- 程序名称：`ZFIR020`
- 适用模块：SAP FI/CO、MM、物料分类账

## 报表用途

按"公司代码 + 估价范围（工厂）+ 物料"查看指定期间的实际成本进销存情况：

- 期初数量、期初金额和期初单价
- 入库数量、入库金额和入库单价
- 出库数量、出库金额和出库单价
- 期末数量、期末金额和期末单价
- 物料类型、评估类和相关描述

**数据来源**：物料估价和物料分类账，不是简单按物料凭证汇总。

## 报表入口

系统中未查询到独立事务码，可通过以下方式进入：

1. SAP 菜单配置的报表入口
2. `SA38` 或 `SE38` → 输入 `ZFIR020` → 执行

## 选择屏幕字段

| 字段 | 必输 | 说明 |
|------|:----:|------|
| 公司代码 | 是 | 核算主体 |
| 会计年度 | 是 | 查询年度 |
| 期间 | 是 | 起始期间；填写起止期间表示累计查询 |
| 工厂/估价范围 | 是 | 按 `BWKEY` 取数 |
| 物料类型 | 否 | 限制原料、半成品、成品等 |
| 物料 | 否 | 具体物料编码 |
| 评估类 | 否 | 财务估价分类 |

## 期间填写规则

**查询单月**（如 2026 年 7 月）：
- 会计年度：`2026`
- 起始期间：`07`
- 截止期间：留空

**查询期间范围**（如 2026 年 1—3 月）：
- 会计年度：`2026`
- 起始期间：`01`
- 截止期间：`03`

## 报表字段说明

### 期初字段
- 期初数量：起始期间开始时的库存数量（`CKMLPP-LBKUM`）
- 期初金额：起始期间开始时的库存价值（`CKMLCR-SALK3`）
- 期初单价：期初金额 ÷ 期初数量

### 入库字段
- 入库数量：物料分类账分类 `PC`（价格更改）、`ZU`（收据）、`VP`（其他接收/消耗）的数量合计
- 入库金额：可能包含价格更改和价格差异
- **注意**：入库不是纯采购或生产入库，还包含价格调整

### 出库字段
- 出库数量：物料分类账分类 `VN`（消耗）的数量
- **注意**：出库数量可能显示负数

### 期末字段
- 期末数量 = 期初数量 + 入库数量 + 出库数量
- 期末金额 = 期初金额 + 入库金额 + 出库金额
- 期末单价 = 期末金额 ÷ 期末数量

## 适合/不适合的场景

**适合**：
- 按物料查看某月的期初、增加、消耗和期末
- 检查物料分类账中的库存数量和实际成本金额
- 分析期初、入库、出库和期末平均单价
- 配合 `CKM3N` 进行物料价格分析

**不适合**：
- 查询具体物料凭证号、移动类型
- 查询采购订单、生产订单
- 查询库存地点、批次
- 作为纯仓储口径的收发存报表

## 对账建议

推荐查询方式：一个公司代码 + 一个工厂 + 一个期间 + 一个物料

对账顺序：
1. `MM03` 确认物料基本单位、价格控制和评估类
2. `CKM3N` 输入相同物料、工厂和期间
3. 核对期初库存数量和金额
4. 核对收据、价格更改、消耗分类
5. 核对价格差异
6. 核对期间是否已完成物料分类账关账
7. 核对货币类型
8. 比较报表期末数量和期末金额

## 已知限制

1. "入库"包含 `PC`、`ZU`、`VP`，不是纯采购或生产入库
2. "出库"仅按 `VN` 消耗分类汇总
3. 报表不显示货币类型和币种
4. 两个单选按钮不影响结果
5. 无法按物料凭证、移动类型、订单、库存地点或批次追溯
6. 报表没有显示评估类型，不适合解释分割评估明细
7. 所有零值物料行可能仍会显示
8. 工厂列实际来源是估价范围 `BWKEY`
