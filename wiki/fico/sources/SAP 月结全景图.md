## 一句话结论
月结的主线是先完成后勤业务和数据清理，再执行 FI/AA/CO 的评估、清账、结算和报表分析；真正不可随意打乱的是后勤先于财务、评估前处理未清项、报表出具前完成期间控制。

## 月结四大阶段总览

| 阶段 | 目标 | 关键动作 |
|------|------|---------|
| **战役一：后勤与业务准备** | 把当月所有业务凭据做完，数据"洁净"进入财务模块 | 发票校验、销售开票、盘点差异、生产订单技术完成、银行对账 |
| **战役二：财务自结准备** | GR/IR 清理、期间管理、预提待摊、自动清账、重分类、汇率和外币评估、折旧及在建工程结算 | F.13/F.19、MMPV/OB52、FBS1/F.81、FAGL_FC_VAL、AFAB |
| **战役三：管理会计结账** | 成本中心分配分摊、作业价格、生产订单在制品和差异、订单结算、物料分类账结算 | KSU5/KSV5、KSS2/KSII、CON2、KKS1/CO88、CKMLCP |
| **战役四：报表与分析** | 资产负债表/利润表、现金流量表、COPA 一致性检查、获利能力分析和 CO 期间关闭 | S_ALR_87012284、KE27、OB52 关闭期间 |

## 财务月结操作要点

### 月结前检查
- 供应商清账完成，可用 `FBL1N` 查询未清/已清项目
- 当月费用录入完成，检查预制凭证是否通过 `FBV0` 过账
- 固定资产折旧通过 `AFAB` 执行

### 期间管理
| 操作 | 事务码 | 说明 |
|------|--------|------|
| 关闭/打开物料期间 | `MMPV` | 后勤物料期间 |
| 查看是否允许前期记账 | `MMRV` |  |
| 打开 FICO 次月期间 | `OB52` |  |
| 维护汇率 | `OB08` | 上月月末最后一个工作日汇率 |

### 评估与重分类
| 操作 | 事务码 | 说明 |
|------|--------|------|
| 外币评估 | `FAGL_FCV` | 先测试运行，再正式运行；必要时可重置评估 |
| AR/AP 重分类 | `FAGLF101` | 正式运行后可能需要在 `SM35` 中处理批输入会话 |
| GR/IR 自动清账 | `F.13` | 必须在 F.19 之前执行 |
| GR/IR 重分类 | `F.19` | 跳过 F.13 会导致报表科目金额虚增 |

### 清账与付款
| 操作 | 事务码 | 说明 |
|------|--------|------|
| 客户清账 | `F-32` |  |
| 供应商清账 | `F-44` |  |
| 付款凭证 | `F-53` |  |

## 成本结转流程

### 成本中心结转
```text
统计指标维护（KB31N）
    ↓
费用分摊（KSU5）
    ↓
费用分配（KSV5）
    ↓
实际价格分割（KSS2）
    ↓
实际价格计算（KSII）
    ↓
重估订单作业成本（CON2）
```

### 生产订单结算
```text
在制品计算（KKAO/KKAX）
    ↓
在制品期间调整（KKA0）
    ↓
产成品差异计算（KKS1/KKS2）
    ↓
订单差异结算（CO88/KO88）
    ↓
检查投入产出（FAGLL03H）
```

### 物料分类账结算
```text
执行物料分类账结算（CKMLCP/CKM3）
    ↓
检查异常未分配差异（CKMVFM/CKMS）
    ↓
执行过账关账（CKMLCP）
    ↓
查看物料实际成本还原（S_P99_41000062）
    ↓
手工调整重分摊费用（F-02/ZCOR005）
    ↓
关闭已结算生产订单（COHVPI）
```

### 项目结算
```text
项目成本分析（CJI3）
    ↓
项目结算（CJ88/CJ8G）
    ↓
查看结算后余额（CJI3）
```

## 关键依赖
- 后勤业务凭据应先完整过账，避免财务结算基于不完整数据。
- GR/IR、应收应付等未清项目应先分析，再进行重分类、评估或结算。
- 生产订单和物料分类账存在跨模块依赖，具体顺序应以企业月结作业链和系统配置为准。
- 关闭 FI/MM/CO 期间属于控制动作，执行前要确认异常清单和审批要求。

## 48 步清单的使用边界
原文整理了 48 个示例动作及事务码，可用于设计月结 Checklist，但其中部分事务码、本地化报表、作业顺序和模块功能受版本、行业方案及企业配置影响。

## 安全与适用边界
月结中的清账、评估、结算和关期间都可能影响财务报表。正式执行前应维护执行顺序、责任人、测试运行/正式运行标志和异常回退方案。
