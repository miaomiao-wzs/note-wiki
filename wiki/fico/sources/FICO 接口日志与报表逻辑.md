# FICO 接口日志与报表逻辑

## 来源信息

- 来源类型：article / Markdown 综合笔记
- 原始位置：`raw/fico/article/202607/FICO.md`
- 适用模块：FICO，涉及 EAS、EC、OA、SRM 及自开发报表
- 整理范围：只提取接口对象、日志入口、字段映射线索和报表取值线索，不复制原始截图中的公司、客户端、科目或账号信息。

## 一句话结论

`FICO.md` 中的接口和自开发报表记录适合作为排查索引，不是跨系统通用接口规范。函数、信道、配置表和日志字段必须以目标系统当前代码、配置和实际消息为准。

### EAS 凭证同步的现场线索

- `ZFIU004` 被记录为考核账凭证记账或失败凭证重新传输入口；是否支持重传、重传前是否需要清理原消息，必须查看目标系统程序和日志状态。
- `ZEASFU007` 日志可作为凭证同步失败的排查入口；原文提到一次性客商行项目顺序、付款凭证匹配条件和分配字段生成逻辑，但这些均依赖接口程序和配置，不应当作为通用接口契约。
- 原文还提到在 `SXI_MONITOR` 中查看消息。目标系统可能使用不同的监控组件或消息框架，应先确认实际架构。
- 不应直接修改接口日志、底表或映射表来“修复”失败；先保存原始消息、错误文本和关联凭证，再按接口重处理机制和变更流程处理。

### 固定资产接口 `ZFIU042`

资料记录的排查线索包括：新资产价值入账可能触发推送，历史资产可能需要手动推送，EAS 侧可能存在变更单或清理单审批；资产映射依赖若干自定义匹配表，具体表名和字段应以目标系统代码为准。原文还提到已推送标识可能影响重复发送判断。

这些内容属于现场经验，尤其是资产已推送标识、重发逻辑、主数据创建和审批边界，必须在测试系统用可追踪的测试资产验证。不得通过直接改自定义表或绕过审批消除接口失败。

## 报表取值逻辑线索

### `ZFIR003` 期间费用/研发费用分析

- 原文记录研发费用分析会汇总特定研发费用科目，并在项目结算后关注结转前后的余额。
- 期间费用分析的报表行、公司维度、功能范围、科目集合和显示描述由自定义配置表 `ZFIT022` 参与决定。
- `ZFIR003` 的具体取数范围必须同时核对程序、`ZFIT022` 当前配置和标准报表结果；不能只依据报表名称或历史截图判断。

### `ZFIR008` SAP Query

原文把 `ZFIR008` 记录为 SAP Query 报表，并列出 `SQ03` 用户组、`SQ02` 信息集和 `SQ01` 查询格式等排查入口。用户组、信息集、生成程序和权限在不同系统可能不同，应以目标系统当前 Query 定义和生成程序为准。

## 建议的排错顺序

1. 明确业务单据、公司范围、接口方向和首次失败时间。
2. 保存脱敏后的消息 ID、错误文本、关联 SAP 凭证/业务单据和重处理状态。
3. 先查应用日志、接口监控和当前配置，再阅读自开发对象代码。
4. 对比源系统与接收系统的字段映射、主数据和状态，不直接改日志或底表。
5. 在测试系统验证重处理、补传或冲销方案，确认幂等性后再按审批执行生产变更。

## 风险与核验边界

> [!warning] 自开发接口不是标准 SAP 结论
> `Z*` 对象、日志表、映射表和消息信道均可能随项目版本变化。本文只保留脱敏后的索引和排查思路，不提供无条件重传、改表或跳过校验的操作步骤。

- 任何接口补传、凭证重处理、主数据同步和字段映射调整都需要授权、测试、备份/回退方案和审计记录。
- 原始资料中出现的真实运行环境标识、默认密码、token 和完整日志不进入本页。
