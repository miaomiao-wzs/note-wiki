# ZFIR020 实际成本进销存报表使用手册

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 程序名称 | `ZFIR020` |
| 程序描述 | 实际成本进销存报表 |
| 适用模块 | SAP FI/CO、MM、物料分类账（Material Ledger） |
| 适用用户 | 财务成本会计、存货会计、工厂财务、SAP FICO/MM 顾问 |
| 文档版本 | V1.0 |
| 编制日期 | 2026-08-20 |
| 编制依据 | SAP S4D 系统中 `ZFIR020` 当前活动版本 |

> 本手册根据程序实际取数逻辑编写，用于帮助业务用户理解报表用途、选择条件、输出字段和使用限制。本文未修改程序。

---

## 2. 报表用途

`ZFIR020` 用于按“公司代码 + 估价范围（通常对应工厂）+ 物料”查看指定期间的实际成本进销存情况，主要包括：

- 期初数量、期初金额和期初单价；
- 所选期间的入库数量、入库金额和入库单价；
- 所选期间的出库数量、出库金额和出库单价；
- 期末数量、期末金额和期末单价；
- 物料类型、评估类和相关描述信息。

报表数据主要来自物料估价和物料分类账，不是简单按照物料凭证汇总。

### 2.1 适合使用的场景

- 按物料查看某月或一段期间的期初、增加、消耗和期末情况；
- 检查物料分类账中的库存数量和实际成本金额；
- 分析期初、入库、出库和期末平均单价；
- 配合 `CKM3N` 进行物料价格分析和成本对账；
- 按物料类型或评估类汇总存货情况。

### 2.2 不适合使用的场景

本报表不能代替物料凭证明细报表，不适合直接用于以下查询：

- 查询具体物料凭证号；
- 查询移动类型，例如 101、261、601；
- 查询采购订单、生产订单或销售订单；
- 查询库存地点、批次或特殊库存明细；
- 查询某一笔入库或出库由哪些业务凭证组成；
- 作为纯仓储口径的收发存报表使用。

如需上述明细，应使用物料凭证、库存或订单相关报表进一步查询。

## 3. 报表入口

系统中目前未查询到直接指向 `ZFIR020` 的独立事务码。可根据公司实际权限，使用以下方式进入：

1. 如果 SAP 菜单已经配置报表入口，优先从业务菜单进入；
2. 否则进入事务码 `SA38` 或 `SE38`；
3. 输入程序名 `ZFIR020`；
4. 点击“执行”或按 `F8`。

> 业务用户通常不一定拥有 `SA38/SE38` 权限。如果无法进入，应联系 SAP 权限管理员确认菜单入口或执行权限。

## 4. 使用前需要准备的信息

执行报表前，至少需要确认：

- 公司代码；
- 会计年度；
- 起始期间，必要时还包括截止期间；
- 估价范围，当前系统通常可理解为工厂；
- 是否需要限制物料、物料类型或评估类；
- 对账金额采用的货币口径；
- 所查期间是否已经完成物料分类账相关关账或实际成本计算。

首次使用或对账时，建议先选择：

- 一个公司代码；
- 一个工厂；
- 一个期间；
- 一个已知物料。

先核对单个物料，再逐步扩大查询范围，避免一次查询范围过大且难以判断差异原因。

## 5. 选择屏幕字段说明

| 选择字段 | 是否必输 | 业务含义 | 填写说明 |
|---|---:|---|---|
| 公司代码 | 是 | 需要查询的法人公司或核算主体 | 只能查询属于该公司代码的估价范围和物料 |
| 会计年度 | 是 | 报表查询年度 | 默认带出当前自然年度，执行历史期间时必须改为对应年度 |
| 期间 | 是 | 起始期间和截止期间 | 只填起始期间表示查询单月；填写起止期间表示累计查询一段期间 |
| 工厂/估价范围 | 是 | 物料的估价范围，程序按 `BWKEY` 取数 | 当前程序把估价范围作为工厂显示，通常填写工厂代码 |
| 物料类型 | 否 | 用于限制原料、半成品、成品等物料类别 | 不填写表示查询所有物料类型 |
| 物料 | 否 | 需要查询的物料编码 | 对账或问题排查时建议填写具体物料 |
| 评估类 | 否 | 物料的财务估价分类 | 可用于按存货科目相关分类筛选物料 |
| 页面单选项 | 否 | 程序保留的两个单选按钮 | 当前活动版本中两个单选项均未参与取数和计算，选择哪个都不会改变报表结果，建议保留默认值 |

### 5.1 期间填写规则

#### 查询单月

例如查询 2026 年 7 月：

- 会计年度：`2026`
- 起始期间：`07`
- 截止期间：留空

此时：

- 期初取 2026 年第 7 期间的期初；
- 入库和出库取 2026 年第 7 期间；
- 期末表示第 7 期间期末。

#### 查询期间范围

例如查询 2026 年 1—3 月：

- 会计年度：`2026`
- 起始期间：`01`
- 截止期间：`03`

此时：

- 期初取第 1 期间的期初；
- 入库和出库累计第 1 至第 3 期间；
- 期末按照“第 1 期间期初 + 第 1 至第 3 期间发生额”计算。

> 建议起始期间小于或等于截止期间。当前程序没有明显的反向期间校验，起止期间填反可能导致无数据或结果无法正确解释。

## 6. 推荐操作步骤

1. 进入 `ZFIR020` 选择屏幕；
2. 输入公司代码；
3. 输入会计年度；
4. 输入起始期间，需要累计查询时再输入截止期间；
5. 输入工厂/估价范围；
6. 根据需要填写物料、物料类型或评估类；
7. 页面单选项保持默认值；
8. 点击“执行”或按 `F8`；
9. 在 ALV 结果中使用筛选、排序、汇总和导出功能；
10. 如需核对金额，选取具体物料与 `CKM3N` 或物料分类账数据进行对照。

### 6.1 推荐查询方式

| 使用目的 | 推荐选择条件 |
|---|---|
| 单个物料对账 | 一个公司代码 + 一个工厂 + 一个期间 + 一个物料 |
| 月度存货分析 | 一个公司代码 + 一个工厂 + 单一期间，可限制物料类型或评估类 |
| 季度累计分析 | 一个公司代码 + 一个工厂 + 起止期间，建议限制物料类型或物料范围 |
| 评估类分析 | 一个公司代码 + 一个工厂 + 一个期间 + 指定评估类 |
| 差异排查 | 一个物料 + 一个期间，随后使用 `CKM3N` 进一步查看 |

## 7. 报表输出字段说明

### 7.1 基础信息字段

| 报表字段 | 字段含义 | 用户应如何理解 | 主要来源 |
|---|---|---|---|
| 公司代码 | 物料所属的公司代码 | 表示该物料估价范围归属的核算主体 | `T001K-BUKRS` |
| 工厂 | 估价范围代码 | 程序显示为工厂，实际取值字段是估价范围 `BWKEY` | `MBEW-BWKEY` |
| 工厂名称 | 工厂描述 | 根据工厂/估价范围匹配的名称 | `T001W-NAME1` |
| 物料号 | SAP 物料编码 | 报表统计的基本对象 | `MBEW-MATNR` |
| 物料描述 | 物料名称 | 按当前 SAP 登录语言显示 | `MAKT-MAKTX` |
| 物料类型 | 物料类别 | 例如原材料、半成品、成品等 | `MARA-MTART` |
| 物料类型描述 | 物料类型名称 | 按当前 SAP 登录语言显示 | `T134T-MTBEZ` |
| 评估类 | 财务估价分类 | 用于确定物料对应的存货科目等财务属性 | `MBEW-BKLAS` |
| 评估类描述 | 评估类名称 | 按当前 SAP 登录语言显示 | `T025T-BKBEZ` |
| 计量单位 | 数量单位 | 通常为物料基本计量单位，例如 KG、EA、盒 | `MARA-MEINS` |

### 7.2 期初字段

| 报表字段 | 字段含义 | 计算或取数口径 | 用户注意事项 |
|---|---|---|---|
| 期初数量 | 起始期间开始时的库存数量 | 主要取物料分类账期间汇总数量 `CKMLPP-LBKUM` | 如果查询 01—03 期间，此字段表示 01 期间期初，不是 03 期间期初 |
| 期初金额 | 起始期间开始时的库存价值 | 主要取 `CKMLCR-SALK3`；部分标准价且实际成本价格确定为 3 的物料还会增加期初价格差异 | 属于物料分类账金额口径，不应直接等同于某一张物料凭证金额 |
| 期初单价 | 起始期间期初平均单价 | 期初金额 ÷ 期初数量 | 期初数量为 0 时不计算，显示为 0 或空值 |

### 7.3 入库字段

| 报表字段 | 字段含义 | 计算或取数口径 | 用户注意事项 |
|---|---|---|---|
| 入库数量 | 所选期间内程序归入“增加项”的数量合计 | 汇总物料分类账分类 `PC`、`ZU`、`VP` 的数量 | 不等于仅采购入库或生产入库数量 |
| 入库金额 | 所选期间内程序归入“增加项”的金额合计 | 移动平均价物料主要取 `STVAL`；其他物料取 `STVAL + PRD` | 可能包含价格更改和价格差异，不是纯收货金额 |
| 入库单价 | 所选期间增加项的平均单价 | 入库金额 ÷ 入库数量 | 如果只有价格调整而没有数量，可能出现“有入库金额但入库数量为 0”，此时单价不会正常反映业务价格 |

程序对物料分类账类别的归类如下：

| 分类代码 | 系统含义 | 本报表处理方式 |
|---|---|---|
| `ZU` | 收据/接收 | 计入入库 |
| `PC` | 价格更改 | 计入入库 |
| `VP` | 其他接收/消耗 | 无论业务名称中包含接收还是消耗，程序统一计入入库 |

因此，本报表中的“入库”更准确地说是程序定义的“增加项”，不是仓库管理口径的纯入库。

### 7.4 出库字段

| 报表字段 | 字段含义 | 计算或取数口径 | 用户注意事项 |
|---|---|---|---|
| 出库数量 | 所选期间内物料分类账消耗数量 | 汇总物料分类账分类 `VN` 的数量 | 消耗通常以负数记录，因此出库数量可能显示为负数 |
| 出库金额 | 所选期间内物料分类账消耗金额 | 移动平均价物料主要取 `STVAL`；其他物料取 `STVAL + PRD` | 通常可能显示为负数，不能看到具体移动类型或凭证 |
| 出库单价 | 所选期间消耗项的平均单价 | 出库金额 ÷ 出库数量 | 当数量和金额同时为负时，计算出的单价通常为正数 |

程序只把物料分类账分类 `VN` 作为出库，因此“出库”更准确地说是物料分类账中的“消耗项”。

### 7.5 期末字段

| 报表字段 | 字段含义 | 计算公式 | 用户注意事项 |
|---|---|---|---|
| 期末数量 | 所选期间结束后的库存数量 | 期初数量 + 入库数量 + 出库数量 | 出库通常为负数，所以公式使用加法 |
| 期末金额 | 所选期间结束后的库存价值 | 期初金额 + 入库金额 + 出库金额 | 金额受物料分类账实际成本和价格差异影响 |
| 期末单价 | 期末库存平均单价 | 期末金额 ÷ 期末数量 | 期末数量为 0 时不计算 |

## 8. 报表结果如何阅读

建议按以下顺序阅读一行数据：

1. 先确认公司代码、工厂、物料和计量单位；
2. 查看期初数量和期初金额是否符合预期；
3. 查看期间入库数量和出库数量；
4. 注意出库数量可能为负数；
5. 使用“期初 + 入库 + 出库”核对期末数量；
6. 使用相同逻辑核对期末金额；
7. 最后分析期初、入库、出库和期末单价的变化；
8. 如果金额变化但数量变化不明显，应重点检查价格更改和价格差异。

### 8.1 示例

假设某物料显示：

| 项目 | 数量 | 金额 |
|---|---:|---:|
| 期初 | 100 | 1,000 |
| 入库 | 50 | 550 |
| 出库 | -30 | -315 |

则：

- 期末数量 = 100 + 50 - 30 = 120；
- 期末金额 = 1,000 + 550 - 315 = 1,235；
- 期末单价 = 1,235 ÷ 120。

> 示例只用于说明报表公式，不代表系统实际数据。

## 9. 金额和币种说明

程序读取期间物料分类账数据时固定使用货币类型 `10`，但报表界面没有显示货币类型和币种字段。

业务用户使用金额列时应遵循以下规则：

1. 不要只看金额数字就自行判断币种；
2. 对外提供或正式对账前，应确认公司代码和物料分类账的货币类型配置；
3. 同一份报表内不要将不同公司代码或不同货币口径的数据混合解释；
4. 如金额与 `CKM3N` 不一致，应先核对货币类型和物料分类账关账状态；
5. 当前程序的期初金额查询没有明确限制货币类型，存在多货币环境下口径不透明的风险。

## 10. 常见问题

### 10.1 为什么“入库金额”与采购入库金额不一致？

因为本报表的入库不是纯采购入库。程序还把价格更改 `PC` 和其他接收/消耗 `VP` 归入入库，标准价物料还可能包含价格差异 `PRD`。

### 10.2 为什么“出库数量”和“出库金额”显示负数？

物料分类账中的消耗通常按负数记录。程序没有把负数转换为正数，而是直接汇总，因此出库列可能显示负数。

### 10.3 为什么有入库金额，但入库数量是 0？

可能发生了价格更改或价格差异，没有发生实际数量接收。程序把这类金额归入入库金额，但数量可能仍为 0。

### 10.4 为什么报表中会出现数量和金额均为 0 的物料？

程序先按物料估价主数据确定查询范围，未强制删除所有零值行。因此只要物料符合公司代码、工厂、物料类型、物料或评估类条件，就可能出现在结果中。

### 10.5 为什么报表结果与仓库库存报表不一致？

本报表基于物料分类账和实际成本口径，不是按库存地点、批次或物料凭证明细汇总。仓储报表和物料分类账报表的用途、时间点和汇总口径不同。

### 10.6 为什么报表无法查看具体凭证？

程序没有读取 `MATDOC`、`MSEG` 或 `MKPF`，也没有输出物料凭证、移动类型、订单、库存地点或批次字段，因此无法从当前报表直接穿透到业务凭证明细。

### 10.7 为什么选择屏幕上的两个单选项没有区别？

当前活动版本中，这两个单选参数没有被后续取数和计算逻辑使用，因此选择哪个都不会改变报表结果。使用时保持默认值即可。

### 10.8 为什么物料描述或评估类描述与其他用户看到的不一致？

物料描述、物料类型描述和评估类描述按 SAP 登录语言读取。不同登录语言可能显示不同文本。

### 10.9 为什么期间关账前后金额可能变化？

本报表使用物料分类账实际成本和价格差异数据。实际成本计算、分摊或物料分类账关账完成后，相关金额可能发生变化。正式月结对账应明确报表运行时点。

### 10.10 为什么分割评估物料需要特别注意？

当前报表没有显示评估类型 `BWTAR`，主要按物料和估价范围汇总。对启用分割评估的物料，应单独核对，不能把报表结果直接理解为某一个评估类型的金额和数量。

## 11. 对账建议

出现差异时，建议选择“一个物料 + 一个工厂 + 一个期间”进行核对。

### 11.1 推荐对账顺序

1. 在 `MM03` 确认物料基本单位、物料类型、价格控制和评估类；
2. 在 `CKM3N` 输入相同物料、工厂和期间；
3. 核对期初库存数量和金额；
4. 核对收据、价格更改、其他接收/消耗和消耗分类；
5. 核对价格差异；
6. 核对期间是否已经完成物料分类账关账；
7. 核对货币类型；
8. 最后再比较报表期末数量和期末金额。

### 11.2 需要技术人员进一步检查的情况

出现以下情况时，建议联系 SAP FICO/MM 顾问或 ABAP 人员：

- 同一物料在报表与 `CKM3N` 的期初金额明显不同；
- 不同币种金额疑似被混合；
- 分割评估物料出现重复或金额重复；
- 有金额但完全没有对应数量；
- 期末数量公式正确，但期末金额不符合实际成本口径；
- 用户需要追溯到物料凭证或移动类型；
- 需要把“入库”改为仅包含采购入库或生产入库。

## 12. 当前程序的已知使用限制

以下内容是当前活动版本的实际限制，用户解释报表时必须注意：

1. “入库”包含 `PC`、`ZU`、`VP`，不是纯采购或生产入库；
2. “出库”仅按 `VN` 消耗分类汇总；
3. 报表不显示货币类型和币种；
4. 期间数据限制货币类型 `10`，但部分期初金额读取没有相同的货币类型限制；
5. 两个单选按钮不影响结果；
6. 无法按物料凭证、移动类型、订单、库存地点或批次追溯；
7. 报表没有显示评估类型，不适合直接解释分割评估明细；
8. 所有零值物料行可能仍会显示；
9. 工厂列实际来源是估价范围 `BWKEY`，依赖系统采用工厂级估价；
10. 报表金额可能随物料分类账关账和实际成本计算状态发生变化。

| 数据内容 | 主要表/字段 |
|---|---|
| 报表物料范围 | `MBEW + MARA + T001K` |
| 公司代码 | `T001K-BUKRS` |
| 工厂/估价范围 | `MBEW-BWKEY` |
| 物料、评估类、价格控制 | `MBEW-MATNR/BKLAS/VPRSV` |
| 物料类型、单位 | `MARA-MTART/MEINS` |
| 物料分类账成本估算编号 | `CKMLHD-KALNR` |
| 期初数量 | `CKMLPP-LBKUM` |
| 期初金额 | `CKMLCR-SALK3` |
| 期间数量和金额 | `MLDOC-QUANT/STVAL/PRD` |
| 物料描述 | `MAKT-MAKTX` |
| 工厂名称 | `T001W-NAME1` |
| 物料类型描述 | `T134T-MTBEZ` |
| 评估类描述 | `T025T-BKBEZ` |

期末数量和期末金额不是直接从数据库读取，而是由程序计算：

- 期末数量 = 期初数量 + 入库数量 + 出库数量；
- 期末金额 = 期初金额 + 入库金额 + 出库金额；
- 各单价 = 对应金额 ÷ 对应数量。

## 14. 用户使用结论

使用 `ZFIR020` 时，应把它理解为：

> 按物料分类账实际成本口径，对物料期初、期间增加、期间消耗和期末进行汇总的进销存分析报表。

不要把它直接理解为：

> 按物料凭证和移动类型统计的仓库收发存明细报表。

业务用户重点记住以下五点即可：

1. 查询时先用“一个工厂、一个期间、一个物料”核对；
2. 出库数量和金额可能显示负数；
3. 入库金额可能包含价格更改和价格差异；
4. 金额列没有显示币种，对外使用前必须确认货币口径；
5. 如需凭证、移动类型、库存地点或批次明细，需要使用其他报表继续查询。
