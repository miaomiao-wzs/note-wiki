# 资产折旧计算逻辑说明

> 文档日期：2026-08-11  
> 适用工具：[通用资产折旧动态测算器](https://miaomiao-wzs.github.io/asset-depreciation-calculator/)  
> 计算口径：剩余寿命直线法、按月折旧、期间累计金额保留 2 位小数

## 1. 文档目的

本文档用于说明通用资产折旧动态测算器采用的计算逻辑，包括：

- 正常月折旧金额如何计算；
- 导入的本年折旧如何与系统目标累计折旧追平；
- 调整期间为什么会产生补提或冲回；
- 调整完成后，后续月份的正常折旧如何计算；
- 调整计划使用年限后，每月折旧和追平金额如何同步变化。

本文档描述的是当前测算器采用的“剩余寿命直线法”逻辑，并不代表 SAP FI-AA 所有折旧码的通用计算规则。

## 4. 核心计算公式

### 4.1 残值金额

```text
残值金额 = 资产原值 × 残值率
```

示例：

```text
33,094.80 × 3% = 992.84
```

### 4.2 剩余可折旧金额

```text
剩余可折旧金额
= 资产原值
− 残值金额
− 导入的往年折旧
```

示例：

```text
33,094.80 − 992.84 − 4,547.84
= 27,554.12
```

这里不直接扣减导入的本年折旧，因为导入的本年折旧将在调整期间与本年度目标累计折旧进行比较，并通过补提或冲回完成追平。

### 4.3 剩余使用月份

```text
剩余使用月份
= 计划使用总月数
− 年初已使用月份
```

示例：

```text
120 − 12 = 108 个月
```

### 4.4 正常月折旧

```text
精确月折旧
= 剩余可折旧金额 ÷ 剩余使用月份
```

示例：

```text
27,554.12 ÷ 108
= 255.1307407407……
```

页面显示金额保留 2 位小数：

```text
正常月折旧 = 255.13−
```

系统期间累计金额仍按未提前截断的精确月折旧计算，然后将累计金额保留 2 位小数。这样可以避免逐月四舍五入造成累计尾差不断扩大。

## 5. 调整期间补提或冲回逻辑

### 5.1 调整期目标累计折旧

假设调整期间是 P007：

```text
P007目标累计折旧
= 精确月折旧 × 7
```

示例：

```text
255.1307407407…… × 7
= 1,785.915185……
≈ 1,785.92
```

### 5.2 系统调整金额

```text
系统调整金额
= 导入的本年折旧
− 调整期目标累计折旧
```

示例：

```text
1,872.64 − 1,785.92
= +86.72
```

因此 P007 需要冲回 86.72：

```text
导入的本年折旧   1,872.64−
系统冲回             86.72+
调整后累计折旧   1,785.92−
```

### 5.3 补提和冲回的判断

| 计算结果 | 业务含义 | 页面显示 |
|---:|---|---:|
| 调整金额大于 0 | 导入折旧高于目标累计折旧，需要冲回 | `+金额` |
| 调整金额小于 0 | 导入折旧低于目标累计折旧，需要补提 | `金额−` |
| 调整金额等于 0 | 导入折旧与目标累计折旧一致 | `0.00` |

## 6. 后续期间正常折旧逻辑

调整完成后，后续月份不再重复比较导入折旧，而是用相邻期间的目标累计折旧差额计算当期折旧。

```text
当期折旧
= 当期目标累计折旧
− 上期目标累计折旧
```

### 6.1 P008计算示例

```text
P008目标累计折旧
= 255.1307407407…… × 8
= 2,041.045925……
≈ 2,041.05
```

```text
P008当期折旧
= 2,041.05 − 1,785.92
= 255.13−
```

因此当前资产在完成 P007 追平后，P008—P012 恢复正常月折旧。

|---|---|---:|

| P008 | 正常折旧 | 255.13− |
| P009 | 正常折旧 | 255.13− |
| P010 | 正常折旧 | 255.13− |
| P011 | 正常折旧 | 255.13− |

## 7. SAP所属期间与领导汇报月份

折旧码采用“次月执行上一折旧期间”的口径时，SAP所属期间和实际执行月份相差一个月。

| SAP所属期间 | 所属月份 | 实际执行月份 | 业务说明 |
|---|---|---|---|
| P007 | 2026年7月 | 2026年8月执行 | 冲回 86.72 |
| P008 | 2026年8月 | 2026年9月执行 | 正常折旧 255.13− |
| P009 | 2026年9月 | 2026年10月执行 | 正常折旧 255.13− |
| P010 | 2026年10月 | 2026年11月执行 | 正常折旧 255.13− |
| P011 | 2026年11月 | 2026年12月执行 | 正常折旧 255.13− |
| P012 | 2026年12月 | 2027年1月执行 | 正常折旧 255.13− |

因此汇报时必须明确使用哪一种时间口径：

- 按 SAP 所属期间说明：7月冲回、8月恢复正常折旧；
- 按领导汇报执行月份说明：8月冲回、9月恢复正常折旧。

## 8. 调整计划使用年限后的计算

调整计划使用年限时，保留以下数据不变：

- 资产原值；
- 残值金额；
- 导入的往年折旧；
- 导入的本年折旧；
- 年初已使用月份；
- 系统调整期间。

重新计算：

1. 剩余使用月份；
2. 正常月折旧；
3. 调整期目标累计折旧；
4. 调整期补提或冲回金额；
5. 后续期间正常折旧。

### 8.1 调整为8年

```text
计划使用总月数 = 96
剩余使用月份 = 96 − 12 = 84
精确月折旧 = 27,554.12 ÷ 84 = 328.025238……
正常月折旧 ≈ 328.03−
```

```text
P007目标累计 = 2,296.18−
P007调整 = 1,872.64 − 2,296.18
          = 423.54−（补提）
```

P008—P012按相邻期间累计差额显示：

```text
328.02−、328.03−、328.02−、328.03−、328.02−
```

### 8.2 保持10年

```text
剩余使用月份 = 108
正常月折旧 ≈ 255.13−
P007调整 = +86.72（冲回）
P008—P012 = 255.13−
```

### 8.3 调整为12年

```text
计划使用总月数 = 144
剩余使用月份 = 144 − 12 = 132
精确月折旧 = 27,554.12 ÷ 132 = 208.743333……
正常月折旧 ≈ 208.74−
```

```text
P007目标累计 = 1,461.20−
P007调整 = 1,872.64 − 1,461.20
          = +411.44（冲回）
```

P008—P012按相邻期间累计差额显示：

```text
208.75−、208.74−、208.74−、208.75−、208.74−
```

### 8.4 年限变化规律

| 年限变化 | 剩余月份变化 | 月折旧变化 | 调整期影响 |
|---|---|---|---|
| 缩短使用年限 | 减少 | 月折旧增加 | 更可能产生补提 |
| 延长使用年限 | 增加 | 月折旧减少 | 更可能产生冲回 |
| 年限不变 | 不变 | 月折旧不变 | 按原目标累计追平 |

## 9. 0.01元舍入差异说明

后续月份可能出现 0.01 元的交替差异，例如 328.02 和 328.03，原因不是计算错误，而是系统先计算各期目标累计折旧，再计算相邻期间累计差额。

```text
P008折旧 = P008目标累计 − P007目标累计
P009折旧 = P009目标累计 − P008目标累计
```

每个目标累计金额都需要保留 2 位小数，所以相邻期间的差额可能相差 0.01 元。最后一期应吸收剩余尾差，确保累计折旧不超过剩余可折旧金额。

## 10. 往年月折旧对比说明

按照原始计划使用年限计算，往年理论正常月折旧为：

```text
（33,094.80 − 992.84）÷ 120
= 267.516333……
≈ 267.52−
```

理论12个月折旧：

```text
267.52 × 12 = 3,210.24
```

导入的往年折旧为：

```text
4,547.84
```

该金额恰好等于：

```text
267.52 × 17 = 4,547.84
```

与理论12个月相比多出：

```text
4,547.84 − 3,210.24
= 1,337.60
= 267.52 × 5个月
```

这说明导入的往年折旧金额相当于17个月的理论月折旧，而资产在2025年度理论上只有12个月折旧。该结论是根据金额进行的反推，需要继续回查原迁移模板、原系统累计折旧截止期间及导入数据口径，不能仅凭金额反推直接认定为迁移错误。

## 12. 适用边界和风险提示

当前测算器适用于以下前提：

- 使用剩余寿命直线法；
- 按月计算折旧；
- 残值率在剩余期间保持不变；
- 调整时保留已有累计折旧；
- 没有特殊折旧、计划外折旧或减值；
- 没有当年新增价值、报废、转移、拆分等资产交易；
- 会计年度按12个正常期间展示。

以下情况不能只依赖本测算器：

- 折旧码不是直线剩余寿命法；
- 期间控制规则不是当月或次月折旧；
- 存在特殊折旧、计划外折旧、减值或资产重估；
- 当年发生后资本化、报废、资产转移或价值调整；
- 使用非日历年度或特殊期间；
- SAP公司代码或折旧范围存在不同的舍入规则。

正式确认金额时，应以 SAP 资产浏览器、计划折旧值、实际折旧过账凭证及对应折旧范围的数据为准。
