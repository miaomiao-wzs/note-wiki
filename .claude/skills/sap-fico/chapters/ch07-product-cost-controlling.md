# Chapter 7: 产品成本控制模块

## Core Idea
产品成本控制（CO-PC）涵盖产品成本计划（标准成本滚算）、实际成本核算（物料分类账）两大核心，是连接CO与后勤模块（MM/PP/SD）的桥梁。

## Frameworks Introduced
- **S价 vs V价控制**: 物料的价格控制决定日常核算使用标准价格（S）还是移动平均价格（V）。S价下标准价格起核算作用，V价下移动平均价起核算作用。
  - When to use: 设计物料的成本核算方案
  - How: 在物料主数据会计视图中设置价格控制标识S或V
  - S价物料月末必须通过物料分类账（CKMLCP）进行差异还原

- **标准成本三步走**: 采购件手工设置标准成本 → 制造件通过CK40N/CK11N滚算 → 通过CK24标记和发布。
  - When to use: 维护制造件的标准成本
  - How: CK11N创建成本估算 → CK24标记为当前标准价格 → CK24发布到物料主数据
- **物料分类账执行**: 物料分类账实际成本核算使用事务码CKMLCP（非CK40N）
  - CK40N：成本估算/成本滚算
  - CKMLCP：物料分类账实际成本核算

## Key Concepts
- **标准价格（S价）**: 在一段时间内保持不变的成本，需人工给定或系统滚算后标记更新
- **移动平均价格（V价）**: 随每次收发货自动重算的实际成本，月末无须差异还原
- **移动平均价公式**: （初始库存价值+库存变动价值）÷（初始库存量+库存变动量）
- **成本滚算（Cost Roll-up）**: 通过BOM和工艺路线逐层计算产品的标准成本
- **物料分类账（Material Ledger）**: 核算物料实际成本的子模块，将差异分摊到存货和损益
- **价格控制标识**: 在物料主数据会计视图中设置，决定物料使用S价还是V价

## Mental Models
- Use "S价=预算思维，V价=实际思维" when choosing price control — S价适合制造业（便于成本控制和差异分析），V价适合贸易业（反映即时成本）
- Think of 标准成本 as "基准线" — 实际成本与标准成本的差异通过物料分类账在月末还原
- Use "移动平均价自动计算" for V价物料 — 系统根据收发货自动更新，无须人工干预

## Anti-patterns
- **S价物料不做月末差异还原**: 按国内会计制度要求，S价物料月末必须通过物料分类账进行成本还原
- **制造件用V价**: 制造件的标准成本一般应由滚算而来，使用V价会导致成本不稳定
- **忽略价格控制对财务报表的影响**: S价下差异需要分摊，V价下价格随采购波动，两者对利润表的影响不同

## Key Takeaways
1. 价格控制（S/V）是物料成本核算的根本决策
2. 制造件的标准成本应通过成本滚算（CK40N）获得，而非手工设置
3. S价物料月末必须通过物料分类账（CKMLCP）进行差异还原
4. V价物料的成本随采购自动更新，无须月末还原
5. 产品成本控制与MM/PP/SD模块高度集成，理解后勤业务是学好CO-PC的前提
