# Chapter 9: 内部订单模块

## Core Idea
内部订单（CO-IOA）是CO模块中灵活的成本归集工具，核心概念是统计型 vs 非统计型内部订单的区分，决定了费用记账时的真实/统计归属。

## Frameworks Introduced
- **统计型 vs 非统计型内部订单**: 内部订单的"统计订单"标识决定了记账性质。统计订单记统计账（还需一个真实记账的成本对象），非统计订单记真实账。
  - When to use: 设计内部订单方案时决定订单类型
  - How: 在订单主数据上勾选"统计订单"复选框

- **费用记账双重归属规则**: 费用同时记入内部订单和成本中心时，必有一个真实记账、一个统计记账，由内部订单的属性决定。
  - When to use: 理解费用记账时内部订单与成本中心的关系
  - How: 统计订单→订单统计/成本中心真实；非统计订单→订单真实/成本中心统计

## Key Concepts
- **内部订单类型**: 决定订单的编号、预置参数、屏幕格式和对象分类
- **对象分类**: INVST（投资）、OCOST（间接费用成本）、PRODT（生产）、PROFT（利润分析）
- **统计订单**: 勾选"统计订单"标识的订单，记账为统计性质
- **非统计订单（真实记账）**: 不勾选"统计订单"标识的订单，记账为真实性质
- **结算规则**: 非统计型内部订单在月末需要定义结算规则，将归集的成本结算到最终对象
- **订单类别**: 1-内部订单（控制）、3-模型订单（控制）

## Mental Models
- Use "统计=看板，非统计=归集" to choose order type — 统计订单用于跟踪管理（如车队费用），非统计订单用于成本归集后结算（如多部门公用资产折旧）
- Think of 内部订单 as "临时容器" — 非统计型订单归集费用后，月末结算到成本中心等最终对象
- Use "双重记账规则" when posting — 同时输入订单和成本中心时，系统自动判断哪个真实/哪个统计

## Anti-patterns
- **多部门公用资产用统计订单**: 应使用非统计型订单，月末结算到多个成本中心
- **车队管理用非统计订单**: 应使用统计型订单，真实过账在车队或行政部
- **忽略结算规则定义**: 非统计型订单必须定义结算规则，否则月末无法将成本结算到最终对象

## Key Takeaways
1. 统计型订单用于跟踪管理，非统计型订单用于成本归集后结算
2. 费用同时记入订单和成本中心时，必有一个真实、一个统计
3. 非统计型订单月末必须结算到最终对象（如成本中心）
4. 最常用的内部订单类型是间接费用订单（OCOST）
5. 订单类型在后台配置，决定编号、参数和屏幕格式
