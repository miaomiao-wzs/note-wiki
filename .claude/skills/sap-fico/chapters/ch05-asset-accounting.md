# Chapter 5: 资产模块

## Core Idea
资产模块管理固定资产的全生命周期（购置→折旧→报废），核心概念是折旧范围、折旧表和资产分类的三层组织结构。

## Frameworks Introduced
- **折旧范围-折旧表层级**: 折旧范围定义单一资产的折旧规则（折旧码、年限、残值率），折旧表是多个折旧范围的组合，分配给公司代码。
  - When to use: 设计资产折旧方案，尤其涉及多准则（会计法/税法/跨国报告）
  - How: 折旧范围01必须存在且为真实折旧范围，通过SM30配置；折旧表通过OAOB分配给公司代码

- **实际折旧范围 vs 衍生折旧范围**: 实际折旧范围直接维护折旧规则，衍生折旧范围由其他折旧范围加减计算得到，常用于分析差额。
  - When to use: 需要对比两个准则下的折旧差异时
  - How: 定义衍生折旧范围时指定计算公式（如62=61-60）

## Key Concepts
- **折旧范围（Depreciation Area）**: 使一个资产适应不同折旧规则的概念，编号01必须存在
- **折旧表（Chart of Depreciation）**: 若干折旧范围的组合，类似总账的科目表概念
- **资产分类（Asset Class）**: 资产的归类，决定资产编号范围和科目分配
- **折旧码（Depreciation Key）**: 定义折旧方法（直线法/加速折旧法）和折旧起始规则
- **过入到总账**: 折旧范围与总账集成的方式——实时过账、定期过账、不过账
- **目标分类账组**: 平行会计下每个折旧范围对应不同的总账分类账组

## Mental Models
- Use "折旧范围01=主折旧范围" as anchor — 它必须是真实折旧范围，必须实时过账，必须对应主分类账组0L
- Think of 多折旧范围 as "多准则并行" — 中国折旧范围用于本地报表，美国折旧范围用于总部报表，衍生折旧范围看差额
- Use "90%企业只用一个折旧范围" as default — 除非有明确的多准则需求，否则只设01即可

## Anti-patterns
- **盲目设置多个折旧范围**: 多数国内企业只需一个折旧范围01，增加折旧范围会增加配置和维护复杂度
- **折旧范围与分类账组不匹配**: 折旧范围01必须对应主分类账组0L，否则数据无法正确传递到总账
- **忽略衍生折旧范围的价值**: 当使用两个实际折旧范围时，应额外定义衍生折旧范围方便查看差额

## Reference Tables

### 折旧范围集成方式
| 选项 | 含义 | 适用场景 |
|------|------|----------|
| 实时过账 | 每笔资产业务实时产生FI凭证 | 折旧范围01（必须） |
| 定期过账 | 月末/年末运行程序批量产生凭证 | 非01折旧范围 |
| 不过账 | 仅在资产模块查询，不反映到FI | 分析用途 |

## Key Takeaways
1. 折旧范围是资产模块的核心概念，01必须存在且实时过账
2. 折旧表是折旧范围的集合，分配给公司代码后生效
3. 多折旧范围适用于多准则场景（会计法/税法、本地/总部）
4. 衍生折旧范围用于计算差额，不产生FI凭证
5. 资产与其他模块高度集成：采购→MM、折旧→CO（成本中心/内部订单）、报废→FI/AR
